# Mindwtr 0.5.9

## Destacados
- El procesamiento de bandeja de entrada móvil es más confiable y admite #etiquetas junto con @contextos.
- La búsqueda móvil ahora abre el proyecto/tarea exacto en el que tocaste.
- El escritorio Linux agrega un selector de decoraciones de ventana y una barra lateral desplazable.

## Escritorio
- Agregar un selector “Decoraciones de ventana” solo para Linux en Configuración → General.
- La lista de barra lateral es desplazable en ventanas pequeñas; el encabezado contraído se ve más limpio.
- Esc ahora desenfoca la entrada quick-add para flujos de trabajo de teclado más rápidos.
- Los resultados de búsqueda de tareas del proyecto siempre abren la vista del proyecto.
- La selección de dirección de texto ahora se guarda correctamente.
- Edición de lista de verificación: Retroceso elimina elementos vacíos y mantiene el enfoque en movimiento.
- Las vistas de lista se actualizan inmediatamente después de ediciones sin actualización.

## Móvil
- La cola de procesamiento de bandeja de entrada permanece abierta y continúa con todas las tareas.
- El procesamiento de bandeja de entrada distingue @contextos vs #etiquetas (las etiquetas se almacenan en etiquetas, no en contextos).
- Los resultados de búsqueda abren el proyecto objetivo y resaltan/abren la tarea.
- La pantalla Contextos admite filtrado de selección múltiple (coincidencia AND) y alternancia para deseleccionar.
- Se agregó relleno de área segura para barras de navegación de Android en Configuración, Revisión, Panel, Esperando, Algún día y Referencia.
- La selección de carpeta de sincronización ahora valida la capacidad de escritura y muestra un mensaje claro de solo lectura.
