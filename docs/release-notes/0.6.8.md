# Mindwtr 0.6.8

## Destacados
- El markdown de descripción ahora admite sintaxis de casilla de verificación de tarea (`[ ]` y `[x]`) y listas de viñetas consistentemente.
- En móvil, tocar una notificación ahora abre la pantalla de Revisión.
- La sincronización es más resistente en móvil y preserva mejor las tareas locales recién creadas durante la fusión.

## Móvil
- Se restauró manejo de archivo de registro de diagnósticos y se mejoró el comportamiento de diagnósticos de sincronización.
- Se mejoró la confiabilidad de programación de notificaciones en Android.
- El texto de configuración de WebDAV ahora claramente solicita una URL de carpeta.
- El historial de sincronización en Configuración se pliega por defecto y puede expandirse.

## Escritorio
- Proteger la ruta de descarga de adjuntos de WebDAV cuando faltan claves de nube.

## Sincronización y WebDAV
- La ruta de fusión de sincronización ahora protege cambios de tareas en memoria cuando las instantáneas persistidas se quedan atrás.
- Mejoras adicionales de seguridad y diagnósticos de WebDAV.
