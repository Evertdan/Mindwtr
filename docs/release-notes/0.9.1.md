# Mindwtr 0.9.1

## Destacados

- La sincronización es más segura bajo contención con ciclos de sincronización serializados, incrementos de revisión limitados, mejor manejo de conflicto de lápida, detalles de historial de eliminación-vs-directo más claros y protección de punto final de texto sin formato más fuerte.
- La captura y planificación móvil son más suaves con protección de guardado duplicado en captura rápida, un estado vacío de Bandeja de Entrada procesable, descubrimiento de consejos para rutas de captura y gestos y reordenamiento de tareas del proyecto.
- Las superficies de control del escritorio son más constantes con una configuración de lanzamiento al inicio, estado de sincronización más claro y advertencias de texto sin formato, solicitudes abiertas de adición rápida global protegidas, deshacer eliminación de proyecto y diseño de etiqueta de tablero corregido.
- El comportamiento del Calendario y Enfoque es más predecible con correcciones de deslizamiento y densidad del calendario móvil, aplazamiento de tareas de inicio futuro y ayudantes de tiempo del compositor compartido.
- El rendimiento y la mantenibilidad se mejoraron a través de mutaciones de tareas basadas en ID, almacenamiento en caché de firma de sincronización estable, selectores de lista de escritorio divididos, exportaciones principales explícitas y nueva cobertura de regresión.

## Sincronización, Nube y Seguridad

- Ciclos de sincronización concurrentes serializados para que la sincronización programada y manual no puedan intercalar ventanas de lectura, fusión y escritura.
- Incrementos de revisión de sincronización limitados en el techo seguro de 32 bits y agregadas advertencias cerca del límite.
- Valores `updatedAt` de lápida utilizados durante el manejo de conflictos y detalles de conflicto de eliminación-vs-directo expuestos en el historial de sincronización.
- Bloqueados puntos finales públicos de sincronización HTTP de texto sin formato mientras se permiten puntos finales de sincronización HTTP privados y locales.
- Fortalecida la creación de ruta de adjunto de Mindwtr Cloud contra carreras de recorrido de enlaces simbólicos.
- Mantenida la sincronización local de WebDAV HTTP funcionando donde los puntos finales privados o locales se usan intencionalmente.

## Móvil Capture, Projects & Calendar

- Se agregó an actionable Inbox empty state and tips discovery for capture paths, gestures, and app shortcuts.
- Se agregó task reordering inside mobile project detail views.
- Se resguardó quick capture against duplicate rapid saves and replaced the remount workaround with explicit open-request state.
- Mejorado mobile calendar swipe behavior, density controls, and follow-up regressions.
- Localized sync activity copy and se eliminó duplicate sync status overlays.
- Eliminado noisy Android bundle warnings and aligned Expo SDK package patch versions.

## Escritorio Experience

- Se agregó a launch-at-startup setting.
- Labeled sync status visibly and aggregated cleartext sync warnings into a single banner.
- Se resguardó global quick add against duplicate open requests.
- Se agregó undo for project deletion and se corrigió board tag overlap.
- Split desktop ListView store selectors so data, settings, and actions subscribe independently.

## Core, Docs & Tests

- Patched hot task-store mutations by ID instead of rebuilding full task arrays for single-task updates.
- Se mantuvo batch task lookup maps aligned during batch updates, deletes, and trash purges.
- Se agregó validated sync signature caching by stable revision.
- Se compartió the serialized async queue helper and calendar composer time helpers through core.
- Se reemplazó core root wildcard exports with explicit named exports.
- Se agregó Caddy HTTPS compose docs, sync conflict recovery docs, Android calendar-sharing notes, llama.cpp endpoint guidance, project reorder gesture docs, and ADRs for sync revision caps and serialized sync cycles.
- Consolidated overlapping deployment and GTD wiki pages.
- Se agregó browser contrast coverage, quick-capture lifecycle coverage, modal accessibility coverage, and regression tests for task lookup alignment and duplicate quick-capture saves.
