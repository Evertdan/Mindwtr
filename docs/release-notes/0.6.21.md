# Mindwtr 0.6.21

## Destacados
- Agregada integración de calendario del sistema en móvil para que los eventos se puedan leer directamente desde los calendarios del dispositivo.
- Agregada sincronización OAuth de Dropbox (móvil + escritorio), incluida la sincronización de adjuntos.
- Reducidos los conflictos falsos de sincronización ignorando la desviación solo de marca de tiempo para registros heredados.
- Mejorada la confiabilidad del escritorio Linux cuando los servicios seguros de llavero no están disponibles para las credenciales de WebDAV.

## Móvil
- Se agregó flujo de integración de calendario del sistema nativo.
- Agregada la sincronización OAuth de Dropbox con manejo de adjuntos.
- Mejorado el comportamiento del widget de Android para priorizar tareas enfocadas y mantener estable la ubicación de captura rápida.
- Endurecidas las rutas de inicialización del temporizador de inicio para mayor confiabilidad de lanzamiento.

## Escritorio
- Agregada la compatibilidad del proveedor de sincronización de Dropbox.
- Agregada la alternativa de credencial de WebDAV para secretos basados en archivos cuando el llavero de la plataforma no está disponible.
- Mejorada la detección de origen de instalación para canales de análisis (incluyendo alias de Homebrew y Microsoft Store).

## Sincronización y Nube
- Mejorada la consistencia de análisis de conflictos de Dropbox en todas las plataformas.
- Prevenida la resurrección de adjuntos eliminados y fortalecida la seguridad de fusión de fijación de marca de tiempo.
- Mejorado el informe de conflictos para evitar inflación solo de desviación.
- Endurecida la validación de ruta de adjunto en la nube.

## Localización
- Expandida y refinada la cobertura de locale alemana.
