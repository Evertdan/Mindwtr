# Mindwtr 0.9.3

## Destacados

- La edición de tareas de escritorio es más rápida con controles de píldora para Estado, Prioridad y Nivel de Energía, chips de fecha rápida y una configuración para edición de vistazo lateral en línea vs. emergente.
- Los flujos de Enfoque y contexto son más claros con filtros de contexto/etiqueta agrupados, filtros de Enfoque guardados reutilizables, virtualización de Enfoque móvil sintonizada y derivación de Agenda de escritorio más ligera.
- La importación de datos móvil ahora admite importar Recordatorios de Apple incompletos a la Bandeja de Entrada mientras deja los recordatorios de origen en Recordatorios de Apple.
- Las suscripciones de calendario manejan la expansión de recurrencia ICS anual de manera más precisa en la ventana del calendario visible.
- Los diagnósticos de sincronización son más explícitos sobre el fijación de marca de tiempo y estadísticas de fusión del lado del servidor, y el desarchive del proyecto ahora restaura el estado de tarea y sección que archive cambió.

## Escritorio Experience

- Se agregó the task editor presentation setting.
- Se reemplazó compact task-attribute dropdowns with accessible pill controls.
- Se agregó quick date shortcuts for common date choices.
- Se agregó Start Fecha to the task quick-action context menu and widened date shortcut popovers.
- Se agregó explicit empty and error states to desktop Agenda so filtered or inbox-only views do not look blank.
- Grouped context/tag filter controls for easier scanning.
- Reused cached task indexes in Agenda to avoid extra full-list scans in Focus.
- Continued the project sidebar sizing and wrapping polish from the 0.9.2 cycle.

## Móvil

- Se agregó Apple Reminders import for incomplete reminders.
- Tuned the Focus list render window for larger lists.
- Abreed archived task details correctly.
- Se mantuvo Expo application metadata available in F-Droid builds.
- Mejorado wrapping for task preview metadata.

## Calendar

- Se ampliaron yearly ICS recurrence soporte, including count-limited yearly events and ordinal weekday yearly patterns.
- Centralized the mobile calendar navigation swipe capture and feedback constants.

## Sync, Cloud & Data Safety

- Se restauró the pre-archive task and section state when unarchiving a project.
- Se evitó re-broadcasting deleted, manually cambió, or moved project-archive records during unarchive.
- Cleared project-archive restore metadata from deleted task tombstones during startup cleanup.
- Treated project-archive restore metadata as opaque for sync conflict signatures.
- Returned server-side merge stats from cloud `/v1/data` writes.
- Counted and surfaced future timestamp clamps in sync diagnostics, including the both-sides-clamped case.
- Required analytics heartbeat callers to provide an explicit fetcher.
- Eliminado a hardcoded Settings day-unit translation map in favor of locale keys.
- Abreing data with 0.9.3 updates the local SQLite schema for project-archive restore metadata; rolling back to older builds after launch is not recommended.
