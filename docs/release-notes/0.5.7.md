# Mindwtr 0.5.7

## Destacados
- Secciones de Proyectos: organizar tareas dentro de proyectos con encabezados de sección, notas y arrastrar y soltar.
- Paridad móvil: asignar secciones en el editor de tareas y ver encabezados de sección en listas de tareas del proyecto.
- Actualizaciones principales: nueva tabla de secciones + sectionId en tareas, más soporte de sincronización y pruebas.

## Escritorio
- La vista del proyecto agrupa tareas por sección con contraer/expandir, notas en línea y agregar rápido por sección.
- Arrastrar tareas entre secciones (incluyendo “Sin Sección”).
- El editor de tareas muestra Sección cuando se selecciona un proyecto.

## Móvil
- El editor de tareas admite selección de sección y creación rápida.
- La lista de tareas del proyecto muestra encabezados de sección y agrupación de “Sin Sección”.
- La pestaña Ver muestra la sección de la tarea cuando corresponde.

## Núcleo
- Modelo de datos de secciones agregado y soporte de almacenamiento/migración (SQLite + almacenamiento web).
- La sincronización ahora fusiona secciones en todos los dispositivos.
- Pruebas para CRUD de sección, limpieza de tareas y comportamiento de sincronización.

## Historial completo de cambios (desde 0.5.6)
- feat(desktop): add project sections
- test(core): cover sections
- fix(mobile): show task sections
- docs: add project sections to guides
