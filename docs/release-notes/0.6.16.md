# Mindwtr 0.6.16

## Destacados
- Endurecimiento de seguridad para adjuntos de sincronización en la nube y manejo de autenticación (decodificación de ruta más segura, escrituras seguras de enlace simbólico, validación de token portador más estricta y scoping de límite de velocidad a nivel de ruta mejorado).
- Correcciones de corrección de sincronización y condición de carrera en escritorio, móvil y núcleo (serialización de sincronización reentrante, seguridad del ciclo de vida del oyente, ordenamiento determinista del proyecto y análisis de marca de tiempo más seguro en fusión).
- Actualizaciones de experiencia del usuario/rendimiento móvil (progreso de acción masiva + flujo de restauración, `getItemLayout` de lista de tareas, memoización del editor de tareas y validación más estricta de adjunto de enlace).
- Mejoras de flujo de trabajo GTD e interfaz de usuario (comprobaciones de proyecto de bandeja de entrada de varios pasos, filtros de persona de espera, renderización más rica de markdown en descripciones de tareas y pulido de accesibilidad adicional).

## Seguridad / Sincronización / Nube
- Se endurecimiento de normalización de ruta de adjunto de nube para bloquear variantes de travesía codificada múltiple.
- Se evitaron problemas de ventana de escritura TOCTOU para escrituras de adjuntos de nube usando flujo de escritura más seguro y comprobaciones de enlace simbólico.
- Se agregó validación de formato de token portador antes de búsqueda y scoping de límite de velocidad `/v1/data` estrechado.
- Se corrigieron carreras de orquestación de sincronización de escritorio y móvil y ordenamiento de limpieza para estabilidad bajo eventos de actualización rápida.
- Se mejoró comportamiento de fusión principal para casos límite de `updatedAt` e ignoró `purgedAt` en difusión de conflicto de contenido.

## Móvil / Escritorio
- Se agregó interfaz de usuario de progreso de eliminación masiva móvil y acción de restauración.
- Se mejoró rendimiento de lista móvil con soporte medido de `getItemLayout` y se redujeron re-renderizaciones de modal grandes.
- Se mejoró estabilidad de entrada/área segura/edición de tarea del teclado en múltiples pantallas móviles.
- Se agregó visibilidad de notificación emergente de error quick-add de escritorio y validación de confirmación de solicitud para entrada vacía.
- Se agregaron etiquetas de accesibilidad faltantes para acciones de proyecto/sección.

## Modelo de Datos / Refactorización / Documentación
- Se centralizaron constantes de color predeterminado de proyecto/área y se eliminaron valores predeterminados hardcoded dispersos.
- Se compartió lógica de limpieza de tarea de referencia duplicada en ayudantes de almacén principal.
- Se expandió cobertura de wiki para implementación en la nube, uso de MCP, orientación de rendimiento y discoverabilidad de nota de versión.
