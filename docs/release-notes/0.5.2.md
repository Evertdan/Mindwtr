# Mindwtr v0.5.2

Lanzamiento date: 2026-01-11

## Destacados
- 🎙️ **Audio quick capture** with automatic speech-to-text and task creation (desktop + mobile).
- 🎯 **Focus view** merges Agenda + Next Actions for a single daily dashboard.
- 🤖 **Local MCP server (MVP)** for LLM automation and scripting.

## Escritorio
- Speech-to-text capture pipeline, model management, and offline Whisper soporte.
- Quick add hotkey se actualizó to **Ctrl+Shift+A**.

- Audio/AI settings refinements and safer download manejo.
