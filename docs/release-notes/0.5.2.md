# Mindwtr v0.5.2

Fecha de lanzamiento: 2026-01-11

## Destacados
- 🎙️ **Captura de audio rápido** con conversión automática de voz a texto y creación de tareas (escritorio + móvil).
- 🎯 **Vista de Focus** fusiona Agenda + Acciones Siguientes en un único panel diario.
- 🤖 **Servidor MCP local (MVP)** para automatización de LLM y scripting.

## Escritorio
- Canalización de captura de voz a texto, gestión de modelos y soporte de Whisper sin conexión.
- La tecla rápida Agregar rápido se actualizó a **Ctrl+Shift+A**.
- Los enlaces externos se abren a través del shell de Tauri.
- Refinamientos de configuración de Audio/IA y manejo de descargas más seguro.

## Móvil
- Captura de voz + flujo de transcripción a tarea.
- Corrección de alineación de estado vacío de vista de Focus.
- Desplazamiento de la lista de proyectos restaurado.
- El menú de Configuración utiliza un icono de engranaje.
- Retraso de pulsación larga de tareas ajustado para el modo de selección.
- La etiqueta de Calendario Externo se actualizó en la configuración.

## Servidor MCP (MVP)
- Solo lectura por defecto, `--write` para habilitar ediciones.
- Herramientas: listar/obtener/agregar/actualizar/completar/eliminar/restaurar tareas + listar proyectos.
- Ruta de escritura de adaptador principal para mutaciones más seguras; SQL reservado para rutas de lectura.
- Documentación mejorada para configuración de Claude/Codex/Gemini + pruebas.

## Documentación
- README se actualizó para vista de Focus + captura de audio.
- Documentación de configuración de MCP expandida.
