# Mindwtr 0.9.5

## Destacados

- Las ubicaciones de tareas ahora son de primera clase en edición, filtrado, búsqueda, almacenamiento sincronizado y tareas creadas por calendario.
- El comportamiento del calendario es más consistente con tareas programadas solo de fecha, tareas de eventos que preservan ubicación, suscripciones ICS gzip, títulos exportados más limpios y limpieza de envío de calendario móvil.
- Las descripciones de tareas Markdown son más fáciles de editar y previsualizar, incluyendo líneas en blanco preservadas y copia de bloque de código admitida en móvil.
- El secuenciamiento de proyectos es más preciso con flujo secuencial de ámbito de sección, visibilidad de tareas completadas en detalle del proyecto y ámbito secuencial persistente a través de la sincronización.
- Sincroniza and packaging reliability improve with safer unchanged-skip checks, calmer idle sync UI, Flatpak reminder fixes, local F-Droid JVM target patching, and clearer heartbeat distribution behavior.

## Task Locations, Search & Scheduling

- Se agregó task location editing and filters across desktop and mobile.
- Se indexó task locations in search and se agregó `location:` / `where:` search operators.
- Se agregó a task ID search operator for precise lookup.
- Cread tasks from external calendar events while preserving event locations.
- Treated date-only scheduled tasks as all-day scheduled work.
- Se preservó task locations in mobile calendar push sync and se eliminó old reference tasks from pushed calendars.
- Decoded gzip ICS subscriptions and se eliminó Mindwtr's title prefix from exported calendar items.

## Editing & Escritorio UX

- Mejorado task description editing and Markdown formatting behavior.
- Se preservó blank lines in Markdown previews.
- Se agregó supported mobile code-block copy behavior.
- Se hizo desktop date pickers close more reliably, honor the configured date format, and align quick-action behavior.
- Se restauró wheel zoom manejo, recentred the desktop quick-add popup, and se agregó a small text size preset.
- Se mantuvo the area filter visible in the collapsed desktop sidebar.
- Re-enabled Flatpak reminders and made Obsidian vault scan retries more reliable.

## Projects, Focus & Sync

- Se agregó section-scoped sequential project flow.
- Muestraed completed tasks in project detail.
- Persisted sequential project scope through sync.
- Se evitó stale unchanged-sync skips after local data changes.
- Calmed mobile idle auto-sync status.
- Eliminad orphaned Mindwtr calendars more reliably.
- Se aclaró heartbeat distribution behavior and shortened the opt-out copy.

## Compilación, Docs & Lanzamiento Reliability

- Patched local Android F-Droid JVM targets.
- Se abordó Bun audit advisories.
- Repaired calendar and mobile test coverage.
- Actualizado calendar sync, search, recurring task, and mobile calendar push documentation.
- Required German AppStream metadata and se agregó an AppStream locale validation gate.
