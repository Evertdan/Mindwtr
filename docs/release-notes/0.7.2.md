# Mindwtr 0.7.2

## Destacados
- Project pickers now respect area scoping during task editing, so large setups surface more relevant projects faster.
- Escritorio performance se mejoró with Agenda virtualization and faster list filtering workflows.
- Móvil reliability se mejoró for Android attachment sync, local reminders, and sync-state feedback.
- Swipe-to-trash on mobile now asks for confirmation to reduce accidental task deletion.

## Escritorio
- Virtualized large Agenda lists for smoother scrolling and lower render cost.
- Agregado inline list filtering and se mejoró keyboard-navigation fallback behavior.
- Quick Add now surfaces custom `#tags` alongside projects and contexts.
- Agregado bulk Area assign/clear actions and se mejoró manual project ordering behavior.
- Restored macOS calendar permission prompting for desktop calendar integration.

## Móvil
- Mejorado Android attachment sync for generic `content://` providers such as Downloads.
- Hardened Android local reminder scheduling and duplicate alarm recovery.
- Agregado delete confirmation before swipe actions move tasks to Trash.
- Mejorado picker accessibility across tasks, projects, sections, and areas.
- Clarified iOS file-sync setup when a provider does not soporte folder selection.
- Móvil project pickers now follow manual ordering and area scoping.

## Core & Sync
- Reduced search overhead by trimming SQLite search payloads and skipping unnecessary project lookups.
- Mejorado save and sync reliability with safer app-data cloning and more robust cloud file writes.
- Resolved mobile sync conflicts now clear back to a healthy state in the sync badge.
