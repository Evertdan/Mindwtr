# Mindwtr 0.9.9

## Destacados

- La planificación es más expresiva con estimaciones de tiempo personalizadas, fechas de vencimiento coloreadas por urgencia, acciones siguientes de fecha límite del proyecto e indicaciones de secuenciamiento de proyectos.
- Las bibliotecas de tareas grandes son más rápidas gracias a la persistencia incremental de tareas, índices de tareas derivados y listas de tareas del proyecto virtualizadas.
- La sincronización de adjuntos es más segura con activos de adjunto de iCloud nativos, sincronización incremental móvil, escaneos de SAF en caché, actualizaciones de adjunto heredadas y estados de archivo faltante más claros.
- La retroalimentación, anuncios, solicitudes de revisión y recordatorios de actualización ahora comparten coordinación de indicador más segura y superficies de retroalimentación de Configuración en compilaciones configuradas.
- Editing, automation, and integrations are steadier with portable Markdown toolbar shortcuts, mid-email Markdown links, external calendar colors, Android context automation receivers, section automation APIs, and French store metadata.

## Planning, Focus & Task Lists

- Se agregó custom time estimates and time estimate filters.
- Se agregó project sequencing help cues and surfaced project deadline next actions in Focus.
- Colored mobile due dates by urgency and se mejoró compact labels for large text.
- Se mantuvo mobile filter search first and persisted Focus group resets.
- Abreed notification task taps in task preview.
- Hid archived projects from quick-add project choices.
- Se actualizó project area titles after merges and indexed project detail tasks more reliably.

## Rendimiento, Storage & Escritorio

- Se agregó incremental task persistence for the desktop SQLite hot path.
- Se agregó derived task indexes and virtualized large project task lists.
- Se actualizó desktop views after external SQLite writes while ignoring local watcher echoes.
- Se resolvió GNOME system theme on startup and allowed desktop window theme updates.
- Se agregó a desktop task-menu action for moving tasks into Focus.
- Cleared Waiting prompt select focus more reliably.

## Sync & Attachments

- Se agregó native iCloud attachment asset sync.
- Se hizo mobile attachment sync incremental.
- Cached SAF attachment scan results and normalized legacy attachment URIs.
- Marked missing cloud attachments clearly.
- Covered legacy attachment upgrade behavior with mobile tests.
- Se documentó iCloud attachment assets in sync docs.

## Editing, Calendar & Automation

- Se agregó portable Markdown toolbar shortcuts and soporte for Markdown links in the middle of email addresses.
- Se evitó duplicate recurring follow-ups.
- Se agregó external calendar colors.
- Se agregó the Android context automation broadcast receiver.
- Se expuso section APIs for automation and preserved task metadata fields through the MCP server.

## Lanzamiento, Calidad & Localization

- Se agregó Android debug APK and profileable internal release workflows.
- Se agregó the release profiling runbook and large-store performance budgets.
- Se restauró partial locale coverage and Markdown toolbar locale coverage.
- Se agregó French store listings and refreshed French sync wording while keeping brand names untranslated.
- Repaired CI expectations for quick add, custom durations, and mobile Focus settings mocks.
