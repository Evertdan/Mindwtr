# Mindwtr 0.9.10

## Destacados

- El Barrido de Mente Guiado ahora está disponible desde Bandeja de Entrada en escritorio y móvil, con grupos de indicadores originales para captura personal y de trabajo.
- La planificación de personas/asignados es más capaz con datos de personas administrados, registros de personas sincronizados, sugerencias conscientes de personas y herramientas de personas MCP.
- Los destinos de sincronización de proveedor de archivos de iOS, como selectores de estilo Drive, son más confiables con acceso de archivo coordinado respaldado por marcador y recuperación de acceso caducado más clara.
- La sincronización y la limpieza de adjuntos son más seguras con solicitudes HTTP nativas acotadas, limpieza de compatibilidad obsoleta, caducidad de eliminación remota pendiente, lápidas más seguras y adjuntos de papelera restaurables.
- Planning, review, and integrations are steadier with board column ordering, weekly inbox processing, follow-up-today actions, Obsidian Dataview metadata import, quick-process shortcuts, and compact mobile Inbox actions.

## Capture, Review & Planning

- Se agregó Guided Mind Sweep prompt groups and localized strings across supported locales.
- Se agregó desktop and mobile Guided Mind Sweep Inbox flows.
- Se agregó Weekly Review inbox processing and a follow-up today review action.
- Se agregó quick process submit shortcut on desktop.

- Se agregó manual task ordering within Board status columns and preserved board order across sorts.

- Centralized project task creation through the quick-add path.

## People, Assignees & Automation

- Se agregó the people manager for task assignees.
- Persisted people data through sync and CloudKit-backed storage.
- Se expuso people list/get tools through the MCP server.
- Actualizado people fixtures and pending remote-delete tombstone tests for CI.

## Sync, Attachments & Storage

- Se agregó stale-aware iOS sync bookmarks, bookmark refresh, and coordinated sync-file reads/writes.
- Stored bookmarks for iOS file-pick sync fallback and routed sync IO through the bookmarked native path.
- Surfaced expired iOS sync access more clearly and handled nil bookmark reads by falling back safely.
- Bounded native HTTP requests for sync backends.
- Recorded fast sync state from write responses and covered self-hosted fast sync writes.
- Sanitized attachment merge metadata and stabilized fallback timestamps.
- Queued and expired pending remote attachment deletes.
- Se preservó attachment tombstones and kept trashed task files restorable.
- Se evitó deleting shared duplicate attachment files.
- Skipped idle desktop attachment cleanup saves.
- Dropped stale live compatibility entities.

## Integrations, Import & Móvil

- Se agregó Obsidian Dataview metadata import.
- Se actualizó sync data silently on mobile.
- Se capturó shared mobile text as task titles.
- Compacted mobile Inbox header actions.
- Mejorado mobile fallback behavior after nil bookmark reads.
- Se agregó Czech locale coverage and refreshed partial locale coverage.
- Actualizado sync and workflow guides and clarified sync merge tie breakers.

## Lanzamiento, FOSS & Calidad

- Se fortaleció Android FOSS release builds by building Expo modules from source, stripping Play-only native modules from autolinking, excluding more Google service groups, and scanning FOSS APKs for Google service contamination.
- Se agregó reusable core and mobile dependency install scripts for release workflows.
- Actualizado release tests for mobile SAF timing, shared attachment utilities, agenda fixtures, people fixtures, and pending remote-delete expectations.
