# Mindwtr 0.6.17

## Destacados
- Se abordaron problemas de confiabilidad de alta prioridad identificados en la revisión integral en sincronización en la nube, núcleo, servidor MCP y edición de tarea móvil.
- Se mejoró experiencia del usuario de sincronización móvil con indicador de estado de sincronización global, comprobaciones de conexión de sincronización, estados vacíos dedicados y etiquetas de accesibilidad mejoradas.
- Se fortaleció corrección de sincronización para adjuntos y persistencia de almacén (preservación de URI vacío, comportamiento de reintento de limpieza remota, robustez de vaciado de cola y semántica de restauración más segura).
- Se endurecimiento de rutas de seguridad y configuración con opt-in de token any de nube explícito y manejo de CLI de modo escritura de MCP más estricto.
- Se estabilizó CI y herramientas corrigiendo cuelgues de modo observación en pruebas de escritorio, restaurando compatibilidad de CI móvil/núcleo y alineando versiones de lint/TypeScript.

## Núcleo / Sincronización / Integridad de Datos
- Se preservaron URIs de adjunto vacío durante deserialización de sqlite para que metadatos pendientes de carga no se eliminen.
- Se agregó seguimiento de reintentos para intentos fallidos de limpieza remota de adjuntos.
- Se corrigió comportamiento de vaciado de almacén para continuar drenando guardados en cola más nuevos después de fallas.
- Se preservó estado de tarea al restaurar tareas eliminadas.
- Se mejoró manejo de caso límite de fusión para `deletedAt` inválido, matrices de adjunto vacío explícitas y fusiones de configuración clonadas profundamente.

## Nube / MCP / Seguridad
- Se hizo cumplir validación de longitud de título de tarea en actualizaciones PATCH de nube.
- Se requirió opt-in explícito para modo autenticación any-token de nube cuando la lista de tokens de autenticación no está configurada.
- Se envolvieron fallos de herramienta MCP en respuestas MCP-compatibles `{ content, isError }`.
- Se estandarizó modo escritura de servidor MCP a `--write`.

## Móvil / Escritorio Experiencia del Usuario
- Se agregó manejo de límite fail-safe móvil para errores de ciclo de vida de audio de modal de edición de tarea.
- Se agregó indicador de estado de sincronización móvil, comprobaciones de conexión de sincronización y cobertura de interfaz de usuario de estado vacío.
- Se mejoraron etiquetas de accesibilidad móvil y se eliminaron etiquetas de estado fallback hardcoded.
- Se corrigieron pancartas de error de sincronización obsoleta mostrándose después de cambiar backend de sincronización a Apagado.
- Se continuaron mejoras de calidad de escritorio (soporte de estado archivado, correcciones de comportamiento de bandeja/dock, pulido de interfaz de usuario).

## Herramientas / Documentación / Pruebas
- Se habilitó ejecución de pruebas de adaptador de sqlite en ejecuciones de vitest principal.
- Se alinearon versiones de espacio de trabajo de ESLint y TypeScript.
- Se corrigieron cuelgues de CI de escritorio asegurando que los scripts de prueba CI se ejecuten en modo sin observación.
- Se actualizaron referencias de documentación y wiki (enlaces de roadmap, correcciones de tabla de guía de desarrollador, limpieza de documentación de contribución).
