# Mindwtr 0.8.3

## Destacados

- Notas Markdown ampliadas en escritorio y móvil con editores de pantalla completa, acciones de barra de herramientas, continuación automática de listas y enlaces internos para tareas y proyectos.
- Se agregó importación DGT GTD más refinamiento de planificación de escritorio, incluidos acordes de teclado de filtro de área, botones claros para fechas de tareas, asignación de energía masiva de contextos y un nuevo filtro de foco de nivel de energía.
- Se mejoró los flujos diarios de móvil con enrutamiento correcto de notificaciones de revisión, acciones de repetición de recordatorio restauradas, retroalimentación de carga de aclaración de IA, hidratación de Hoy mejor e indicaciones de enseñanza en estados vacíos.
- Se fortaleció la sincronización y los diagnósticos preservando valores recuperables de `createdAt` durante la reparación de fusión, vaciando escrituras pendientes antes de la recuperación de reintento y mejorando la recuperación de arranque de SQLite de MCP.

## Notas, Edición y Navegación

- Se agregó editores Markdown ampliados, un flujo estable de barra de herramientas/pantalla completa, continuación automática de listas y enlaces internos de tareas/proyectos con navegación escrita más affordances de restauración de elementos eliminados.
- Se agregó importación DGT GTD JSON/ZIP y documentación para el flujo de importación.
- Se agregó atajos de teclado de escritorio para filtrado de áreas y se expusieron fuentes de detección de Obsidian TaskNotes.
- Se reemplazaron affordances de UI con iconos pesados en emoji con equivalentes de Lucide en escritorio y móvil, incluida configuración de sincronización y estados clave vacíos.

## Planificación, Móvil y Uso Diario

- Se agregó un filtro de nivel de energía en Focus, asignación de energía masiva desde contextos de escritorio, y botones claros para fechas de tareas de escritorio.
- Se hizo que las secciones de navegación de escritorio sean contraíbles con estado persistente y se mantuvo el estado de colapso de área estable en la navegación.
- Se mejoró el enrutamiento de revisión móvil, comportamiento de repetición de recordatorio, localización de marcador de posición de búsqueda, hidratación de foco Hoy, e indicaciones de enseñanza en estados vacíos de Hecho y Referencia.
- Se mantuvieron traducciones incompletas de holandés fuera de selectores de idioma hasta que la configuración regional esté lista.

## Sincronización, Confiabilidad y Documentación

- Se preservaron valores recuperables de `createdAt` durante la reparación de fusión y se vaciaron las escrituras pendientes antes de la recuperación de reintento.
- Se mejoró la recuperación de arranque de MCP con registro SQLite y cobertura de ruta de escritura, mientras se mantiene intactos los análisis del canal de instalación.
- Se aclaró la configuración de punto final compatible con OpenAI, requisitos de HTTPS en la nube y se alineó el idioma de ADR/wiki de sincronización con el comportamiento enviado.
- Se ampliaron las guías de repositorio alrededor de enlaces Markdown, importación DGT, atajos de teclado, Pomodoro, listas reutilizables e sincronización en la nube.
