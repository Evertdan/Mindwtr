# Mindwtr 0.6.19

## Destacados
- Strengthened sync correctness across core, desktop, and mobile, including attachment-state persistence, earlier timestamp normalization, and stricter merged settings sanitization.
- Mejorado mobile experience with better sync cadence behavior, safer widget data manejo, Copilot loading feedback, and smoother quick-add flow.
- Mejorado desktop task/attachment UX with stale-load guards, blob URL lifecycle cleanup, accessibility error announcements, and filtering feedback.
- Hardened cloud and MCP surfaces with stricter validation, bounded rate-limiting, and pagination improvements.

## Sync / Core
- Corregido desktop sync dropping attachment mutation metadata after attachment processing.
- Moved timestamp normalization before merge conflict resolution to avoid inconsistent winners.
- Agregado merged-settings sanitization safeguards to avoid malformed remote settings corrupting local state.
- Aligned task visibility behavior between helper filtering and query paths.
- Agregado additional sync race coverage (delete-vs-update, rapid add/delete interleaving, cloud merge edge cases).

## Escritorio
- Corregido attachment audio loading race conditions and cleaned up blob URLs on unmount.
- Agregado screen-reader friendly attachment error announcements.
- Agregado filtering/loading indicator in large filtered list views.
- Reduced task row rerender overhead by stabilizing/memoizing key callbacks and props.

## Móvil
- Corregido stale closure behavior in sync cadence manejo.
- Mejorado quick add by dismissing keyboard after submit.
- Agregado Copilot "thinking" loading state.
- Hardened Android widget payload building and sync-config value validation.
- Mejorado iOS sync edge cases (version/path manejo) and widget/theme behavior.

## Cloud / MCP / CI
- Hardened cloud API security and resilience: stricter token/path manejo, pagination, and bounded rate-limit key growth.
- Agregado cloud merge tests for delete/update race behavior.
- Tightened MCP tool input schemas and made preflight migration failures explicit.
- Enabled TestFlight external tester notifications in iOS/macOS App Store workflows.
