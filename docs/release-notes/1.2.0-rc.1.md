# Mindwtr 1.2.0-rc.1

This release candidate focuses on safer sync and storage recovery, more useful calendar planning, and faster everyday task work across desktop and mobile.

## Destacados

- Ocultas tasks with a timed start from Focus and Next until their exact start time.
- Projects every occurrence of a repeating task across the visible calendar range.
- Validates a new sync destination with a full read, merge, write, and attachment check before activating it.
- Prevents stale recovery snapshots and edits made during a fast sync check from being lost.
- Fetches current AI and speech model lists from configured providers, with se actualizó OpenAI and Anthropic suggestions.
- Adds a complete Swedish translation, bringing Mindwtr to 20 languages.
- Makes search results more informative and reliably opens completed or archived desktop tasks.
- Improves mobile list performance, drag recovery, accessibility, and project navigation.

## Pruebas focus

- Actualizar from v1.1.6, then create, edit, complete, delete, and restore tasks; restart and verify every change persists.
- Configurar each sync provider in a new location and an existing location, including a deliberate validation failure; verify the previous working setup remains active or sync fails closed.
- Edit while an automatic sync is checking for changes and verify the edit reaches the remote copy on the queued pass.
- Comprueba daily, weekly, monthly, and bounded recurring tasks across calendar ranges; confirm projected occurrences remain read-only.
- Give a task a timed start and verify Focus, Next, filtered searches, and Daily Review reveal it at the intended times.
- Prueba provider model discovery and remote speech-to-text with OpenAI-compatible, Gemini, and fallback configurations.
- En móvil, reorder a long list, edit and complete visible rows, use a screen reader, and add a task from a project opened through the Projects tab.
- En Linux, test Flatpak system calendars and KDE Wayland theme, window controls, and alt-tab behavior.

## Sync, storage, and security

- Nuevo and cambió sync destinations are activated only after Mindwtr can read, merge, write, and account for every live attachment. A failed validation keeps the last verified setup; an unverifiable rollback leaves sync off.
- Móvil recovery resumes writes only after applying the exact healthy database snapshot that was loaded, preventing stale in-memory data from overwriting recovered tasks.
- A local edit arriving during the fast unchanged check queues another sync pass instead of being reported as synced too early.
- Fresh Local File Sync folders no longer fail their first sync with an undefined-object error.
- Escritorio stores saved passwords, sync tokens, and API keys in a file readable only by the current user account.
- Windows sync again uses the Windows certificate engine, restoring compatibility with corporate TLS interception while macOS and Linux retain TLS 1.3 soporte.
- The weekly AI review ignores suggestions for tasks that were not part of the reviewed input.

## Tasks, Focus, search, and calendar

- Focus and Next hide tasks with a timed start until the exact time; affected filtered searches refresh at midnight and at the next start time.
- Calendar paints all projected occurrences of a repeating task across the visible month, week, or schedule range while respecting spacing, COUNT, and UNTIL limits.
- Busca results label completion and due dates on desktop and mobile.
- Escritorio search opens done and archived tasks in the correct grouped list, reveals the matching row, and explains when an archive filter was cleared.
- The project picker searches every project when an Area is selected while keeping that area's projects as the initial suggestions.
- Focus group headers now match the uppercase style used by other grouped lists.
- Contexto dots and calendar colors use Nord-flavored accents without changing stored color values.
- Russian now translates “No area” as “Нет области”.

## AI and voice capture

- Provider-backed model pickers load the configured provider's current model list, with built-in suggestions as the fallback and local Whisper remaining offline.
- AbreAI `gpt-transcribe` is available and is the default for new OpenAI speech-to-text setups; current Gemini speech models are available again on mobile.
- Built-in AI suggestions include the GPT-5.6 family and Claude Opus 5 while preserving saved and manually entered model ids.

## Móvil

- Task row updates avoid re-rendering every visible row, reducing action lag in large projects.
- Drag-list cells reset after dragging, preventing permanent gaps and overlapping rows.
- Adding a task from a project opened through the Projects tab returns to that project.
- The Add Task Area chip displays its icon consistently with Contexts and Project.
- Task rows announce localized Estado and Due labels and direct screen-reader users to the accessibility actions menu.

## Escritorio and Linux

- Scheduling controls are quieter: reminders and recurrence collapse into readable summaries, and Start and Review dates sit with the other dates.
- Enter confirms and closes Start Fecha, Due Fecha, Review Fecha, Area, and Contexts quick-action panels.
- The Plan next-actions panel remains expandable at narrow and wide window sizes.
- Flatpak system calendars no longer load conflicting Evolution Data Servidor libraries.
- KDE Plasma starts with the correct system dark theme, Wayland titlebar controls recover after hidden reveals, and deb/rpm alt-tab entries show the Mindwtr icon.

## Languages and product polish

- Swedish (Svenska) is fully translated on desktop and mobile, bringing the interface to 20 languages.
- The feedback form explains that the optional email field is how the user receives a reply.
