# Mindwtr 0.7.3

## Destacados
- Unified desktop and mobile sync orchestration for more consistent queued-sync behavior and fewer stale-state edge cases.
- Hardened local persistence, search, and self-hosted cloud merge manejo to reduce data-loss and corruption risks.
- Agregado date and time format overrides plus opt-in inbox processing settings for more control over daily workflows.
- Mejorado mobile sync visibility and reminder reliability, while tightening desktop project organization and diagnostics.

## Escritorio
- Agregado drag-and-drop project moves across areas for easier large-project organization.
- Agregado date and time format overrides and opt-in inbox processing settings in desktop Settings.
- Mejorado calendar weekday localization and se agregó settings-open diagnostics.
- Restored macOS calendar permission prompting and guarded EventKit enum manejo.
- Corregido several sync timing and file-watcher edge cases, including stale default sync-folder creation.

## Móvil
- Agregado a visible sync activity indicator and se mejoró WebDAV rate-limit manejo.
- Mejorado task editing and inbox processing flows, including safer close confirmation and tab-state recovery.
- Hardened local notification scheduling, alarm-map recovery, and Android reminder behavior.
- Mejorado board/task editing reliability and reduced duplicate or stale reminder edge cases.

## Core, Cloud & Automation
- Agregado bounded save retries with backoff and stronger snapshot/tombstone safeguards.
- Mejorado sync merge behavior, attachment validation, and SQLite search/index reliability.
- Hardened self-hosted cloud sync with safer namespace locking, protected task creation fields, and more consistent read behavior.
- The MCP server now correctly honors explicit readonly mode.
- CLI and local API automation now share the desktop storage model more consistently.

## Docs & Lanzamiento Tooling
- Agregado ADRs for SQLite WAL/FTS5, tombstone retention, and the shared Zustand state model.
- Consolidated deprecated wiki pages and se agregó CI coverage plus Playwright E2E coverage to the release pipeline.
- Actualizado GitHub Actions pins for the Node 24 transition.
