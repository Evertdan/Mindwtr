# Mindwtr 0.7.3

## Destacados
- Unificada la orquestación de sincronización de escritorio y móvil para un comportamiento de sincronización en cola más consistente y menos casos extremos de estado obsoleto.
- Endurecida la persistencia local, búsqueda y manejo de fusión de nube autohospedada para reducir riesgos de pérdida de datos y corrupción.
- Agregadas anulaciones de formato de fecha y hora más configuración de procesamiento de bandeja de entrada opcional para más control sobre flujos de trabajo diarios.
- Mejorada la visibilidad de sincronización móvil y confiabilidad de recordatorios, mientras se aprieta la organización de proyectos de escritorio y diagnósticos.

## Escritorio
- Se agregó movimiento de arrastrar y soltar de proyectos entre áreas para una organización más fácil de proyectos grandes.
- Agregadas anulaciones de formato de fecha y hora y configuración de procesamiento de bandeja de entrada opcional en Configuración de escritorio.
- Mejorada la localización de día de semana del calendario y agregados diagnósticos de apertura de configuración.
- Restauradas las indicaciones de permiso de calendario de macOS y guardado el manejo de enum de EventKit.
- Corregidos varios casos extremos de tiempo de sincronización y observador de archivos, incluyendo creación obsoleta de carpeta de sincronización predeterminada.

## Móvil
- Se agregó indicador de actividad de sincronización visible y mejorado el manejo del límite de velocidad de WebDAV.
- Mejorados flujos de edición de tareas y procesamiento de bandeja de entrada, incluida confirmación de cierre más segura y recuperación de estado de pestaña.
- Endurecida la programación de notificaciones locales, recuperación de mapa de alarma y comportamiento de recordatorio de Android.
- Mejorada la confiabilidad de edición de tablero/tarea y reducidos casos extremos de recordatorio duplicado u obsoleto.

## Núcleo, Nube y Automatización
- Se agregós reintentos de guardado acotados con retroceso y salvaguardas de instantánea/lápida más fuertes.
- Mejorado el comportamiento de fusión de sincronización, validación de adjuntos y confiabilidad de búsqueda/índice de SQLite.
- Endurecida la sincronización de nube autohospedada con bloqueo de espacio de nombres más seguro, campos de creación de tareas protegidos y comportamiento de lectura más consistente.
- El servidor MCP ahora honra correctamente el modo de solo lectura explícito.
- Automatización de CLI y API local ahora comparten el modelo de almacenamiento de escritorio de manera más consistente.

## Documentación y Herramientas de Lanzamiento
- Se agregós ADRs para SQLite WAL/FTS5, retención de lápida y modelo de estado compartido Zustand.
- Consolidadas páginas de wiki deprecadas y agregada cobertura de CI más cobertura de E2E de Playwright al pipeline de lanzamiento.
- Actualizado los pins de GitHub Actions para la transición de Node 24.
