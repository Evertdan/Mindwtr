# Mindwtr 0.6.0

## Destacados
- Mejoras de seguridad de sincronización con mejor visibilidad de conflictos, registro de normalización de marca de tiempo y coalescencia de escritura más segura.
- Pulido de experiencia del usuario de escritorio: notificaciones emergentes, advertencias de ediciones no guardadas y estados de carga/deshabilitados más claros durante acciones de proyecto y masivas.
- Actualizaciones de rendimiento principal, incluyendo cargas de SQLite paginadas y bloqueo más seguro de reconstrucción de FTS.

## Escritorio
- Agregar notificaciones emergentes para acciones clave.
- Advertir antes de navegar con ediciones de tareas no guardadas.
- Mejorar la accesibilidad para alertas y controles solo icono.
- Mostrar estado de carga mientras se obtiene, y deshabilitar acciones crear/eliminar/masivas mientras se ejecutan.
- Deshabilitar controles de adjuntos mientras se cargan.

## Móvil
- Sincronizar configuración de tema con configuración principal.
- Mejorar consistencia de registro y tipificación para errores de sincronización/almacenamiento.

## Núcleo y Sincronización
- Evitar que la coalescencia de escritura de sincronización pierda cambios concurrentes.
- Validar entradas de creación de tareas y proyectos.
- Registrar detalles de normalización de marca de tiempo durante fusiones de sincronización.
- Compartir ayudantes HTTP de sincronización en backends.
- Proteger reconstrucciones de FTS con un bloqueo y reutilizar caché de orden del proyecto.
- Cargas de SQLite de página para mejorar el rendimiento.

## Nube
- Podar entradas de caché de límite de velocidad para evitar crecimiento ilimitado.
- Usar registro estructurado en todos los servidores.

## Documentación y Desarrollo
- Agregar diagrama de arquitectura y expandir documentación de CLI/API/MCP.
- Agregar una prueba de instantánea de edición rápida y punto de referencia de utilidades de tareas.
