# Mindwtr 0.5.5

## Destacados
- Correcciones de estabilidad de lanzamiento: resolver regresiones de pantalla blanca de Linux y mejorar diagnósticos para compilaciones de lanzamiento.
- Correcciones de inicio de SQLite: indexación segura del orden del proyecto y migraciones de activadores FTS sin contenido.
- Pulido de sincronización + configuración: backend de sincronización predeterminado desactivado hasta configurarse y metadatos de lanzamiento de Winget mejorados.

## Escritorio
- Agregar modo de diagnósticos para compilaciones de lanzamiento (devtools/registro opcional).
- Evitar ciclos de fragmentos de proveedor que podrían romper WebKitGTK en Linux.
- Mantener la sincronización deshabilitada por defecto hasta que se configure un backend.

## Núcleo / Base de datos
- Proteger la creación de índice de orden del proyecto cuando esquemas antiguos carecen de `orderNum`.
- Migrar activadores FTS sin contenido a semántica de eliminación adecuada y flujo de reconstrucción.

## Documentación / CI
- Establecer metadatos de ubicación de instalación de Winget para envíos exitosos.
- Orientación de instalación de wiki actualizada (Winget/Scoop).
