# Mindwtr 0.7.1

## Destacados
- Reduced false-positive sync conflicts by normalizing noisy revision/order-only changes and pruning stale sync metadata.
- Mejorado Focus workflows: more reliable "Top 3" behavior, clearer Next Actions grouping, and cleaner list controls.
- Agregado deterministic context color indicators and lightweight grouping options to improve task scanning without UI bloat.
- Hardened cloud and file-sync reliability, including better offline/error manejo and WebDAV recovery safeguards.

## Móvil
- Mejorado sync lifecycle reliability around attachment/orphan cleanup and pre-sync persistence.
- Agregado quick-capture accessibility labeling improvements.
- Mejorado large list responsiveness by virtualizing project/context pickers.
- Actualizado widget theme manejo to better follow native color-scheme changes.

## Escritorio
- Agregado local search bars in key views and se mejoró keyboard fallback navigation in non-list pages.
- Mejorado keybinding UX and help completeness for Vim/Emacs styles.
- Agregado Focus Next Actions grouping controls (`No grouping`, `Contexto`, `Area`) with minimal visual styling.
- Mejorado task/list interaction quality (double-click edit behavior, selector consistency, and focused control styling).

## Sync & Cloud
- Reduced conflict noise from order drift and `revBy`-only churn.
- Mejorado sync stability when offline or when remote payloads are partially stale/corrupted.
- Agregado cleanup for stale pending remote-delete metadata and orphan attachment bookkeeping.
- Hardened cloud write-lock and auth/error paths.

## Localization
- Agregado missing recurrence repeat-on translation coverage in non-English locales.
- Agregado multiple zh-Hant and general i18n consistency fixes.
