# Mindwtr 0.4.6

## Destacados
- Se agregaron traducciones al español, alemán y japonés con cobertura más amplia.
- La aplicación móvil ahora admite orientación horizontal en tabletas.
- Las versiones de macOS ahora incluyen compilaciones de Apple Silicon e Intel.

## Escritorio
- Las etiquetas de idioma de Configuración ahora se traducen correctamente más allá del chino.
- El flujo de trabajo de Lanzamiento compila artefactos `macos-arm64` y `macos-x64`.

## Móvil
- Rotación horizontal habilitada (`orientation: default`).
- Expo Go vuelve correctamente al almacenamiento JSON y deshabilita las notificaciones.
- Se agregó mapeo de símbolo SF faltante para el icono de papelera.

## Núcleo
- Cobertura de traducción expandida para Configuración + cadenas de interfaz de usuario comunes.
