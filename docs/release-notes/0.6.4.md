# Mindwtr 0.6.4

## Destacados
- Filtro de Área global (“cambio de sombrero”) en todas las vistas, más asignación de área para tareas independientes.
- Duplicar proyectos en escritorio para listas de verificación reutilizables.
- Alternancias de modo compacto/densidad y refinamientos de diseño de tablero para mejor escaneo.
- El widget móvil puede completar tareas; se corrigieron los pasos de procesamiento de bandeja de entrada.

## Escritorio
- Agregar un filtro de Área global en la barra lateral y reflejarlo en toda la interfaz de usuario.
- Duplicar proyectos desde la barra lateral (copia profunda con estado de tarea fresco).
- Alternancia de densidad en encabezados de lista + atajo de teclado; limpieza de etiqueta de detalles compactos.
- Espaciado de vista de tablero + refinamientos de controlador de arrastre.
- Reemplazar confirmación de descarte con un modal personalizado y mejorar comportamiento de modal de revisión.
- Habilitar notificaciones nativas.

## Móvil
- El widget ahora admite completar tareas.
- Corregir pasos de procesamiento de bandeja de entrada y problemas de superposición de diseño.
- Endurecimiento de rutas de descarga de modelo de Whisper sin conexión; solicitar permiso de notificación en compilaciones independientes.

## Núcleo y Datos
- La vista de Focus ahora respeta la hora de inicio; las tareas recurrentes mantienen horas de inicio sin establecer por defecto.
- Normalizar marcas de tiempo en la carga y advertir sobre fallos de bloqueo de FTS.
- Agregar soporte de API REST para sincronización auto-alojada.
