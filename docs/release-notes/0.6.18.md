# Mindwtr 0.6.18

## Destacados
- Se corrigió ruido de interfaz de usuario móvil eliminando la pancarta de sincronización `Conflicts resolved` obsoleta.
- Se mantuvieron análiticas de latido completamente silenciosas para usuarios en móvil mientras se preserva comportamiento de latido diario en compilaciones oficiales.
- Se estandarizó cableado de punto final de latido en canalizaciones de lanzamiento Android/iOS/escritorio que no sean FOSS.
- Se mejoró confiabilidad de lanzamiento para tiendas corrigiendo metadatos de dependencia de Winget y endurecimiento de manejo de versión editable de iOS App Store.

## Móvil
- Se suprimió carry-over de pancarta de error/éxito de sincronización obsoleto en flujo de inicio de aplicación móvil.
- Se habilitaron valores predeterminados edge-to-edge y se eliminaron anulaciones de color de barra de estado/navegación obsoletas.
- Se eliminó permiso `FOREGROUND_SERVICE_MEDIA_PLAYBACK` no utilizado.
- Se aseguró que los errores de latido permanezcan invisibles para el usuario y no disruptivos.

## Lanzamiento / CI / Distribución
- Se conectó `ANALYTICS_HEARTBEAT_URL` desde secretos de repositorio en todos los flujos de trabajo de lanzamiento que no sean FOSS.
- Se eliminó inyección de manifiesto de Winget de dependencia `Microsoft.EdgeWebView2Runtime` para evitar fallos de validación de dependencia faltante.
- Se actualizó automatización de carga de iOS App Store para crear/editar versiones de aplicación de manera segura cuando no existe versión editable.
