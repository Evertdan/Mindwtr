- Corregido a Play Store Android startup crash (`undefined is not a function`) caused by tab-bar path serialization in release builds.
- Agregado retry/backoff for Linux repo release-asset download to reduce transient GitHub API failures.

- Hardened `publish-repo` release asset download with retries when GitHub API returns transient failures (for example, HTTP 502).
