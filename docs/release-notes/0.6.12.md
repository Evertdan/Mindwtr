# Mindwtr 0.6.12

## Destacados
- Se corrigió un bloqueo de inicio de Android de Play Store (`undefined is not a function`) causado por serialización de ruta de barra de pestañas en compilaciones de lanzamiento.
- Se agregó reintento/retroceso para descarga de recurso de lanzamiento de repositorio de Linux para reducir fallos transitorios de API de GitHub.

## Móvil
- Se reemplazó la ruta de renderización de barra de pestañas nativa para evitar fallos de serialización de ruta solo de lanzamiento.
- Mantiene el comportamiento de captura rápida y el flujo de navegación de pestañas intactos mientras previene bucles de bloqueo de inicio.

## CI
- Se endurecimiento de descarga de recurso de lanzamiento `publish-repo` con reintentos cuando la API de GitHub devuelve fallos transitorios (por ejemplo, HTTP 502).
