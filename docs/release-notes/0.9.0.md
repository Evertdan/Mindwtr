# Mindwtr 0.9.0

## Destacados

- Enfoque y Pomodoro son más claros: el vinculamiento de tareas es opcional, los controles del temporizador se separan de las acciones de tareas, la selección de tareas anterior sobrevive a los cambios de vinculación y el Enfoque móvil explica tareas con inicio futuro oculto.
- La programación es más precisa con inicios futuros ocultos de forma predeterminada, recordatorios de inicio/vencimiento divididos, acciones de finalización de notificación y un control de densidad del calendario de semana móvil ajustable.
- La búsqueda y captura son más rápidas: la adición rápida de escritorio se abre como una ventana emergente, la búsqueda de escritorio cubre todas las áreas globalmente y los resultados de búsqueda global están acotados para mantener las bibliotecas grandes receptivas.
- La sincronización es más segura y visible con diagnósticos de descarte de eliminación-vs-edición, reintentos de escritura pendiente limitados, reparación de lápida obsoleta, poda SQLite en lotes, reprogramación de notificación acotada, errores de sincronización móvil que ahora permanecen visibles y limitación de velocidad de autenticación en la nube más fuerte.
- Las superficies de configuración y estado móvil son más fáciles de escanear con pantallas secundarias GTD, estado de error de sincronización más claro y deshacer eliminación para flujos de lista de tareas/edición.

## Enfoque, Calendario y Recordatorios

- Ocultadas tareas de inicio futuro de forma predeterminada y agregada adecuación compacta de "inicio futuro oculto" donde se aplica el filtro.
- Recordatorios de inicio y vencimiento divididos en flujos de notificación separados y corregidas claves de alarma de notificación de revisión.
- Agregada densidad del calendario de semana móvil, comportamiento de deslizamiento de mes restaurado, calendario de semana abierto en el día seleccionado y documentado lo que significa la escala de densidad.
- Permitido a usuarios móviles completar tareas directamente desde notificaciones.
- Hecho el vinculamiento de tareas de Pomodoro opcional, acciones de temporizador y tareas separadas, retrocesos de localización de tarea de vinculación agregados y contexto de tareas seleccionadas preservado en viajes de ida y vuelta de alternar vinculación.

## Búsqueda, Captura y Configuración GTD

- Adición rápida global de escritorio abierta en una ventana emergente.
- Búsqueda de todas las áreas globalmente en escritorio y representación de búsqueda global acotada a los primeros 200 resultados con una sugerencia de desbordamiento.
- Acción de edición-eliminación de bandeja de entrada de escritorio agregada.
- Configuración de visibilidad de edad de tarea agregada.
- Configuración de GTD móvil dividida en pantallas secundarias para Pomodoro, captura, revisión, bandeja de entrada, archivo, estimaciones de tiempo y editor de tareas.
- Streamlined mobile context selection and refined review controls.

## Sync, Cloud & Rendimiento

- Logged `syncConflictDiscarded` diagnostics when a delete wins over a live edit.
- Capped pending remote-write retries and surfaced sync errors in mobile status UI.
- Repaired stale area references on tombstones and normalized area content comparisons.
- First sync after upgrading may transfer slightly more than usual while tombstone metadata converges.
- Batched SQLite pruning temp-table inserts and made temp table names collision-resistant.
- Capped and batched mobile local notification rescheduling to the nearest upcoming alarms.
- Rate-limited cloud auth failures primarily by IP, then by token namespace.
- Se apretó future-start visibility defaults in core utilities.

## Docs & Accesibilidad

- Actualizado README característica lists for global quick add, global search, mobile week density, split start/due reminders, and the Pomodoro custom preset.
- Se agregó ADRs for area soft-delete cascades, split start/due reminders, and the planned shared sync orchestration boundary.
- Se documentó the tombstone purge consistency bound and delete-vs-live diagnostics in the sync algorithm wiki.
- Se agregó desktop Pomodoro axe coverage and native mobile accessibility metadata for week density controls.
