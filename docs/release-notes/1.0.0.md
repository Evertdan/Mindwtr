# Mindwtr 1.0.0

## Destacados

- Mindwtr 1.0.0 publica el ayudante de automatización MCP local como el paquete npm público `mindwtr-mcp` y servidor de Registro MCP `io.github.dongdongbh/mindwtr`, con manejo de campo anulable más seguro, comprobaciones de publicación idempotentes y cobertura de lint sin advertencias.
- La sincronización y el almacenamiento local son más seguros para uso multidispositivo y multiproceso: los datos de personas sobreviven a las rutas de copia de seguridad y sincronización, los bucles de personas duplicadas se detienen, las escrituras de contenedor de revisión inferior no pueden sobrescribir filas más nuevas y la eliminación de proyecto o área desvincula el trabajo en lugar de perderlo.
- Los adjuntos y la duplicación de proyectos son más seguros con archivos remotos compartidos preservados y metadatos de adjunto de proyecto duplicado borrados en lugar de reutilizar claves remotas obsoletas.
- Los flujos de captura móvil, calendario, proyecto y lista grande son más suaves con expansión de Captura Rápida segura para teclado, activos de icono de Android actualizados, mejor accesibilidad, búsquedas de enlaces Markdown indexadas, contabilidad de altura de fila mixta y menos sincronizaciones de ciclo de vida sin operación.
- Escritorio, PWA, cloud, and local automation paths are steadier with remembered cloud tokens, stricter PWA CSP headers, recurring task creation through the local API, restored autocomplete caret manejo, finalized cloud task writes, and faster auth-token digest checks.
- Documentación and release quality se mejoró with refreshed sync/MCP/wiki guidance, core and cloud lint/typecheck coverage, cloud write-path tests, recurrence parity tests, and Android/mobile coverage gates.

## MCP, API Local y Automatización

- Published the MCP server as `mindwtr-mcp` and se agregó MCP Registry metadata.
- Se hizo MCP registry publishing idempotent for release reruns.
- Se preservó nullable field clears through MCP writes.
- Se mantuvo MCP linting zero-warning clean.
- Cread recurring tasks correctly through the desktop local API.
- Se documentó current MCP npm and registry setup.

## Sincronización, Almacenamiento y Seguridad de Datos

- Se restauró deleted people and preserved people through mobile backup storage.
- Se detuvo duplicate people sync loops and pinned people load-normalization convergence.
- Se agregó revision guards to container SQLite upserts for areas, projects, sections, and people.
- Detached tasks when deleting projects and clarified area/container delete outcomes.
- Se preservó shared remote attachment files and cleared attachment metadata on project duplicates.
- Se compartió local freshness guards and suppressed no-op mobile lifecycle syncs.
- Finalized cloud task route writes, se agregó cloud write-path coverage, and precomputed auth token digests.

## Móvil, Escritorio y Refinamiento Web

- Se mantuvo Quick Capture expansion above the keyboard and gated the More expansion on keyboard hide.
- Mejorado mobile calendar and project accessibility.
- Refined Android adaptive and monochrome icon assets.
- Se indexó mobile and desktop Markdown link lookups for faster large-note rendering.
- Se contabilizó for mixed task-list row heights on mobile.
- Se restauró the desktop task input caret after autocomplete.
- Permitir the PWA remember cloud tokens and se agregó stricter PWA CSP headers.
- Localized the Markdown copy-code label and cleaned Portuguese locale whitespace.

## Docs, CI & Lanzamiento Calidad

- Actualizado workflow, sync, cloud, Docker, MCP, roadmap, and Core API documentation.
- Se agregó an engineering principles checklist for high-risk write, sync, and packaging changes.
- Se agregó core and cloud to typecheck and lint coverage.
- Se agregó recurrence local API parity coverage and refreshed mobile sync harness tests.
- Se expuso mobile coverage gates locally.
