# Mindwtr 0.8.7

## Destacados

- La importación de OmniFocus es más completa: Mindwtr ahora acepta exportaciones JSON y ZIP, mapea carpetas de OmniFocus en áreas, preserva reglas de repetición soportadas y convierte tareas anidadas en elementos de lista de verificación cuando es posible.
- Las sesiones de Pomodoro pueden avanzar automáticamente de enfoque a descanso y de descanso a enfoque, con configuración en escritorio y móvil más retroalimentación de finalización más clara.
- El manejo de tareas de escritorio es más rápido con un menú de acciones rápidas de clic derecho/Más para fechas vencidas, contextos, duplicado y eliminación, más estado de pantalla completa restaurado en lanzamientos.
- La sincronización es más sólida entre proveedores con manejo más seguro de colecciones de WebDAV, alternativa de lectura de Dropbox en escritorio, mejor manejo de lápida/conflicto, limpieza de comparación de adjuntos, normalización de recurrencia e índices de conflicto nuevos.
- Focus móvil ahora muestra tareas vencidas de revisión, la captura rápida evita el fantasma de hoja de Android, la accesibilidad del selector se ha mejorado y las listas de tareas medias se desplazan más suavemente.
- La automatización de lanzamiento ahora valida la paridad de clave de locale e imágenes de tienda, prepara activos de listado de App Store/Google Play/Microsoft Store y evita que los metadatos de Flathub re-agreguen permisos de D-Bus de instancia única rechazados.

## Escritorio, Importación y Pomodoro

- Agregado menú de acciones rápidas de tareas en escritorio, disponible desde clic derecho o el botón Más, para acciones rápidas de fecha vencida, contexto, duplicado y eliminación.
- Persistente estado de pantalla completa de escritorio para que la aplicación restaure la preferencia de pantalla completa del usuario en el próximo lanzamiento.
- Configuraciones de GTD avanzadas contraídas en secciones de divulgación para que las opciones de característica, captura, revisión, bandeja de entrada y editor de tareas sean más fáciles de escanear.
- Ocultado el URI de redireccionamiento de Dropbox hasta que comience la autenticación de Dropbox, reduciendo ruido en la configuración de Sincronización.
- Ampliada la importación de OmniFocus desde cobertura solo CSV a exportaciones JSON y ZIP con áreas, hijos de lista de verificación, recurrencia, etiquetas, fechas, notas, vistas previas y advertencias.
- Agregada configuración de auto-inicio de Pomodoro para descansos y sesiones de enfoque, compartido el comportamiento en escritorio y móvil y mostrado un aviso único cuando se habilita el auto-inicio.

## Sincronización e Fiabilidad

- Fortalecidas escrituras de WebDAV normalizando URL de colecciones, sondeando colecciones existentes después de conflictos y enviando la sugerencia `X-NC-WebDAV-AutoMkcol` para cargas JSON y de archivo.
- Reintentadas lecturas remotas de Dropbox de escritorio con una alternativa de búsqueda de navegador cuando la ruta de búsqueda nativa no devuelve datos.
- Reducidos conflictos falsos ignorando derivación de transporte/tiempo de ejecución de adjunto en firmas de contenido de tarea y proyecto.
- Mejorado manejo de conflicto de lápida, normalización de comparación nula/vacía, estado de reintento de escritura remota pendiente y filtrado de eliminación.
- Normalizados valores de recurrencia al cargar datos de SQLite para que cadenas de recurrencia heredadas no se filtren en el estado de tarea de tiempo de ejecución.
- Agregados índices de SQLite para escaneos de conflicto de sincronización y búsquedas de área de proyecto activo; las bases de datos locales grandes pueden ver un retraso de inicio único mientras se crean los índices.
- Agregada cobertura de fusión de nube para fusiones de datos concurrentes y misma tarea, más cobertura de persistencia de estado de adjunto local.

## Móvil, Accesibilidad & Localization

- Se agregó a dedicated Review Due section to mobile Focus so tasks with due review dates are visible alongside focus, schedule, and next-action lists.
- Switched Android quick capture sheet animation away from transparent sliding modals to avoid ghosted sheet trails on affected tablet GPUs.
- Mejorado quick capture picker accessibility with modal semantics, headers, list roles, and selected states.
- Lowered the clipping threshold for medium mobile task lists to improve scroll performance.
- Se compartió the fallback translation helper across desktop and mobile UI code and se agregó locale key parity checks to CI.
- Se ampliaron Dutch locale parity and filled missing Italian fallback keys for sync, import, recurrence, and accessibility copy.

## Lanzamiento & Store Automation

- Se agregó CI checks for locale parity and store image assets.
- Se agregó scripts and workflow wiring to prepare Fastlane screenshots for iOS and macOS App Store uploads.
- Se agregó Google Play listing asset preparation/upload soporte.
- Actualizado Microsoft Store publishing to use repo-managed screenshots and 16:9 promotional art.
- Se agregó App Store, Google Play, and Microsoft Store listing screenshots/assets for this release.
- Actualizado Flathub checkout automation so it removes previously injected single-instance D-Bus finish args instead of re-adding entries Flathub rejects.
- Actualizado architecture, cloud sync, attachment sync, OmniFocus import, and release-process documentation.
