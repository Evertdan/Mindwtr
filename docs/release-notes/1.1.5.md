# Mindwtr 1.1.5

## Destacados

- Los guardados móviles permanecen receptivos en bibliotecas grandes a través de SQLite nativo, copias de seguridad de seguridad fusionadas, detección de cambios más barata y trabajo en segundo plano serializado.
- Los proyectos recuerdan su propio orden de tareas, el Enfoque de Hoy admite ordenamiento manual, los filtros pueden excluir contextos y etiquetas y Done puede agrupar por fecha de finalización.
- La captura maneja más formatos de fecha y comillas, las importaciones multilínea usan una escritura segura y los Atajos de iOS aplican las mismas reglas de adición rápida que las aplicaciones.
- Las tareas recurrentes mantienen su identidad de serie, aplazan correctamente las ocurrencias futuras e honran los intervalos de repetición después de la finalización.
- Escritorio adds email capture, Linux system calendars, broader keyboard control, task and attachment drag-and-drop, saved window geometry, and quiet tray startup.
- Móvil gains sturdier Android reminders and widgets, better large-text and keyboard layouts, clearer write failures, and a compact Pomodoro card.
- Backup restores remain authoritative after sync, mobile credentials move to platform secure storage, and WebDAV, proxy, iCloud, and self-hosted sync paths report and recover from failures more reliably.
- MCP adds authenticated HTTP transport, speech to text supports self-hosted OpenAI-compatible servers, and cloud writes follow the same task rules as local apps.
