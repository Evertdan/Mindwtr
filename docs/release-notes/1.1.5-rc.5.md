# Mindwtr 1.1.5-rc.5

This release candidate focuses on persistence reliability, mobile performance, and cross-platform workflow polish.

## Destacados

- Prevents Windows close hangs by surfacing stalled saves and flushing pending work before exit.
- Strengthens storage, import, search-index, and sync migration paths.
- Improves large-project performance, filtering, global search, task editing, and offline speech on mobile.
- Correcciones calendar overlap layout, projected-repeat keyboard actions, and date-only project review scheduling.
- Adds completion backdating, time-spent capture, and focused-project next-action warnings.

## Pruebas focus

- En Windows, edit a task and close normally and during a simulated save stall; verify data persists and no background process remains.
- Re-import the same DGT backup, sync twice, and reopen the app; verify no duplicates, missing fields, or unexpected second-sync changes.
- En Android, reorder a long project, use filters and global search, edit a task, and download/use an offline Whisper model.
- In desktop calendar and keyboard flows, verify only real overlaps stack and projected repeats do not receive task actions.
- Backdate a completion, record time spent, and verify focused active projects without a next action show a warning.
