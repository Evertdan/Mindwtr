# Mindwtr v0.4.7

## Destacados
- **Procesamiento de Bandeja de Entrada (Escritorio + Móvil):** Se agregó un paso **Refinar** dedicado (editar primero el título/descripción) para reducir la carga cognitiva y mantener los pasos posteriores de solo lectura.
- **Tablero Kanban:** Anchos de columna adaptables nuevamente para que el tablero se escale en los monitores mientras aún permite desplazamiento horizontal cuando es necesario.
- **Editor de Tareas (Escritorio):** El editor ahora se desplaza internamente para que Guardar/Cancelar nunca desaparezca de la pantalla.
- **Tecla rápida de Captura Rápida (Linux):** El atajo global predeterminado se actualizó a **Ctrl+Alt+M** para mejor compatibilidad con WM.
- **Proveedores de IA:** Se agregó **Anthropic (Claude)** con alternancia “thinking” opcional e IDs de modelo de Claude actualizados.
- **Instalador de Windows:** Se cambió a paquetes NSIS para mejorar el comportamiento de actualización/sobrescritura.
- **Agenda:** Se eliminó el límite de 5 elementos para que todas las Acciones Siguientes elegibles aparezcan en la selección de Agenda.
- **Áreas:** Se agregaron controles de ordenamiento (A–Z, por color) y controles de reordenamiento manual.

## Sincronización y Almacenamiento
- SQLite sigue siendo el almacén local principal con puente de sincronización/copia de seguridad JSON para flujos de trabajo de sincronización de archivos.

## Recurrencia y Programación
- El manejo semanal de BYDAY se mejoró (por ejemplo, lun/mié/vie). 
- La recurrencia fluida continúa rodando desde la finalización mientras preserva el comportamiento de inicio/vencimiento.

## Localización
- Soporte de idioma expandido (incluyendo español, alemán, japonés y más).

## Miscelánea
- Se agregaron pruebas para lógica de fecha/recurrencia principal y prueba de humo de componente móvil.

Si encuentras algún problema, por favor abre un problema con registros de depuración habilitados (Configuración → Sincronización → Diagnósticos).
