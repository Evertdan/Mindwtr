# Mindwtr v0.4.7

## Destacados
- **Inbox Processing (Escritorio + Móvil):** Agregado a dedicated **Refine** step (edit title/description first) to reduce cognitive load and keep later steps read‑only.
- **Kanban Board:** Adaptive column widths again so the board scales across monitors while still allowing horizontal scroll when needed.
- **Task Editor (Escritorio):** Editor now scrolls internally so Save/Cancel never disappear off‑screen.
- **Quick Capture Hotkey (Linux):** Default global shortcut se actualizó to **Ctrl+Alt+M** for better WM compatibility.
- **AI Providers:** Agregado **Anthropic (Claude)** with optional “thinking” toggle and se actualizó Claude model IDs.
- **Windows Installer:** Switched to NSIS bundles to improve update/overwrite behavior.
- **Agenda:** Eliminado the 5‑item cap so all eligible Next Actions appear in Agenda selection.
- **Areas:** Agregado sorting controls (A–Z, by color) and manual reordering controls.

## Sync & Storage
- SQLite remains the primary local store with JSON sync/backup bridge for file sync workflows.

## Recurrence & Scheduling
- Weekly BYDAY manejo se mejoró (e.g., Mon/Wed/Fri). 
- Fluid recurrence continues to roll from completion while preserving start/due behavior.

## Localization
- Expanded language soporte (including Spanish, German, Japanese, and more).

## Miscelánea
- Agregado tests for core date/recurrence logic and a mobile component smoke test.

If you spot any issues, please file an issue with debug logs enabled (Settings → Sync → Diagnostics).
