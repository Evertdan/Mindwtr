# Mindwtr 0.4.4

## Destacados
- La divulgación progresiva en editores de tareas (escritorio + móvil) mantiene el formulario predeterminado limpio mientras muestra todos los campos que ya rellenaste.
- Modos Focus/Zen: Modo Focus de escritorio (ocultar barra lateral, ancho de lectura de 800px) y Modo Zen móvil (top 3 para Hoy).
- Nuevas señales principales: recurrencia fluida, conteo de procrastinación (push) y estados de estado del proyecto.

## Escritorio
- El editor de tareas ahora comienza de manera mínima y revela campos avanzados con “Más opciones”.
- Las tarjetas de tareas se abren en una vista de solo lectura; presiona editar (o `e`) para entrar en modo edición.
- Modo Focus (Ctrl+\ / Cmd+\) oculta la barra lateral y centra la lista.
- Selector de estado del proyecto y agrupación de barra lateral para Activo vs Algún día/Esperando.
- El selector “Solo los 3 principales” de la Agenda ahora usa los depósitos de agenda visibles.

## Móvil
- El editor de tareas usa divulgación progresiva con “Más opciones”.
- El Modo Zen de Agenda muestra solo las 3 tareas principales de Hoy y oculta los vencidos.
- La captura rápida mantiene la entrada enfocada; el texto de ayuda se oculta detrás de un selector sutil.

## Núcleo
- La recurrencia admite estrategias `estrictas` y `fluidas`.
- El contador de push de tareas se incrementa cuando las fechas de vencimiento se reprograman más tarde.
- Estados de estado del proyecto: `activo`, `algún día`, `esperando`, `archivado`.

## Documentación
- Documentación actualizada para reflejar el nuevo comportamiento del editor, modos Focus/Zen y campos principales.
