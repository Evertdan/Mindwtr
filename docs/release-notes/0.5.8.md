# Mindwtr 0.5.8

## Destacados
- La captura de Android ahora predeterminadamente usa entrada de texto, con sugerencias de bandeja de entrada más claras cuando la captura de voz está habilitada.
- El procesamiento de bandeja de entrada de escritorio ya no repite el paso Proyecto cuando “Proyecto primero” está habilitado.
- La vista de Panel puede expandirse a ancho completo en pantallas grandes.

## Escritorio
- El procesamiento de bandeja de entrada respeta “Proyecto primero” sin pedir Proyecto dos veces.
- La vista de Panel utiliza ancho completo para mostrar más columnas en monitores amplios.

## Móvil
- El método de captura predeterminado es texto para nuevas instalaciones.
- “Buscar actualizaciones” abre la lista de Google Play en Android.
- La vista Referencia ya no muestra agregar rápido.
- La página Proyectos elimina la fila de filtro de área duplicada.
