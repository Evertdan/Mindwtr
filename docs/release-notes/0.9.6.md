# Mindwtr 0.9.6

## Destacados

- La planificación del calendario ahora admite envío de Calendario de Apple de macOS, fuentes ICS locales en móvil y vistas previas de solo planificación para la próxima recurrencia sin crear tareas reales.
- Las listas de tareas móvil ganaron controles de filtro, chips de filtro más claros, fragmentos Markdown mejores y edición de Markdown/lista de verificación segura para teclado.
- La edición de proyecto y tarea de escritorio se siente más constante con navegación de proyecto contraíble, píldoras de metadatos seleccionadas más fuertes, corrector ortográfico nativo y comportamiento de Markdown/lista de verificación más confiable.
- La integración de plataforma es más confiable en toda la automatización de contexto de Android, captura de Siri repetida, comportamiento de bandeja de Flatpak, detección de tema GNOME, chrome oscuro de Windows y activación de bandeja de escritorio.
- Sincroniza and diagnostics are quieter and safer, including preserved recurrence-preview data, duplicate calendar-push protection, and fewer duplicate conflict toasts.

## Calendar, Recurrence & Focus

- Se agregó one-way macOS Mindwtr -> Apple Calendar push through EventKit.
- Se agregó **Show next occurrence in Calendar** for recurring tasks as a planning-only preview.
- Se preservó `showFutureRecurrence` across CloudKit, self-hosted cloud, SQLite, and sync helper paths.
- Se agregó local ICS calendar sources on mobile.
- Se evitó duplicate pushed calendar events after transient update/delete failures.
- Se alineó Focus next-action sorting, priority grouping, and task-age behavior.
- Se aclaró calendar and Focus sorting documentation.

## Móvil UX & Automation

- Se agregó mobile task-list filters with polished controls, clearer chip labels, and better accessibility.
- Se agregó Android context automation intents for activating and deactivating contexts from shortcuts and integrations.
- Mejorado Markdown task snippets with nested lists and inline code.
- Se mantuvo Markdown pairing and URL-paste selections steadier on Android.
- Se mantuvo inbox and task-editor inputs above the keyboard, including Markdown toolbar and checklist editing paths.
- Se hizo Markdown toolbar buttons adaptive and se corrigió icon sizing, including the italic control.
- Se mantuvo project next-action prompts mounted beyond row unmounts and surfaced failed prompt actions.
- Reopened repeated Siri capture shortcut runs more reliably.
- Mejorado attachment action layout on mobile.

## Escritorio UX

- Se agregó a collapsible project panel.
- Emphasized selected status and metadata pills in task editing.
- Se habilitó native spellcheck for descriptions.
- Se preservó expanded Markdown editor cursor visibility.
- Refined the inbox project dropdown and se eliminó the quick-add window backdrop.
- Muestraed task ID matches in global search.
- Se mantuvo tray activation from restoring a minimized window incorrectly.
- Se mantuvo the Flatpak desktop app running in the tray.
- Polled GNOME system theme preference and applied dark theme to Windows chrome.

## Markdown, Checklists & Sync

- Se hizo Enter and Tab behavior list-aware in Markdown editing.
- Sincronizaed Markdown checklist state more consistently.
- Se suprimió duplicate desktop sync conflict toasts.
- Mejorado diagnostics toggle framing and clarified heartbeat diagnostics copy.
- Repaired calendar push checks and tightened release verification docs.
- Optimized mobile store listing metadata and refreshed README sponsor presentation.
