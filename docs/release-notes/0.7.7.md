# Mindwtr 0.7.7

## Destacados
- Enfocada esta versión de parche en correcciones de confiabilidad en toda la sincronización de escritorio, edición de tareas móviles y conversión de voz a texto, autenticación de nube autohospedada y valores predeterminados de empaquetado de lanzamiento.
- Mejorado el comportamiento del escritorio en configuraciones de Linux y AppImage con actualizaciones de tema del sistema en vivo, comportamiento de sincronización de desenfoque/enfoque más seguro y manejo mejor de llamadas de stat del sistema de archivos bloqueadas.
- Endurecida la captura de voz móvil y diagnósticos en Android mientras se corrigen regresiones del editor de tareas y informes de estado de sincronización/conflicto obsoletos.
- Apretadas las reglas de fusión y validación en sincronización central, persistencia de SQLite, limitación de velocidad de autenticación en la nube y manejo de entrada de adición rápida MCP.

## Escritorio
- Seguir cambios de luz/oscuridad del sistema de manera más confiable, incluyendo limpieza del observador de temas nativos en sistemas más lentos.
- Pausar sincronización automática desencadenada por desenfoque mientras se editan tareas para que los cambios de estado no sincronicen ediciones en progreso.
- Siempre libera oyentes sin conexión después de fallas de sincronización y mejora la compatibilidad con comprobaciones de stat del sistema de archivos bloqueadas al escanear bóvedas Obsidian.
- Detectar instalaciones de análisis de Flathub con más precisión para flujos de empaquetado/informes de escritorio.

## Móvil
- Restaurado el campo Proyecto en el editor de tareas móvil cuando la compatibilidad del proyecto está habilitada.
- Endurecida la conversión de voz a texto de Android, carga de Whisper y diagnósticos de transcripción de OpenAI, y corregidas las actualizaciones de voz para usar el ID de tarea creado.
- Detalles de conflicto de sincronización obsoletos borrados después de fallas posteriores de sincronización y corregida la escritura de Blob para ayudantes de carga de voz.

## Sincronización, Nube, MCP y Núcleo
- Prevenidas las limitaciones de velocidad de fallo de autenticación en la nube de colapsar clientes no relacionados en un cubo compartido cuando los encabezados proxy no son de confianza.
- Preservado el ordenamiento entre marcas de tiempo futuras fijadas durante la fusión y mantenido seguro el ordenamiento de escritura de clave externa SQLite para registros relacionados.
- Agregada cobertura de regresión alrededor del comportamiento de eliminación de proyecto de SQLite.
- Limitada la longitud de entrada de `quickAdd` de MCP y alineada la validación con manejo de entrada recortada.

## Documentación, Empaquetado y Lanzamiento
- Endurecidos los valores predeterminados de Docker con configuración explícita de token de autenticación, imágenes de Bun fijadas y límites de recursos de composición.
- Aclarada la cobertura de wiki/docs para la compatibilidad de API REST en la nube de Docker y el comportamiento actual de fusión de sincronización.
- Corregidas las traducciones de etiquetas comunes francesas y actualizadas las comprobaciones de lanzamiento/CI para compilaciones seguras de Flathub y F-Droid.
