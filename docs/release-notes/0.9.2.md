# Mindwtr 0.9.2

## Destacados

- La navegación móvil, Enfoque, Configuración, Revisión, calendario y superficies de captura se actualizaron para que la planificación diaria y la captura de bandeja de entrada se sientan más directas.
- La captura de Android ganó más puntos de entrada: captura de Configuración Rápida, atajos de Acciones de Aplicación e intenciones de creación de nota de voz compatibles con asistente, todas se enrutan al flujo de captura de confirmación primero.
- La sincronización es más resistente con sincronización de filtro guardado, sincronización de límite de enfoque, manejo más estricto de huella digital de WebDAV/nube, compatibilidad de tarea de sincronización en segundo plano y cancelación de adjunto más segura en todos los backends.
- Las vistas de escritorio son más constantes con opciones de vista persistentes, filtros restaurados durante el inicio, un pie de página de sincronización más limpio, comportamiento de actualización de adición rápida mejorado y conteos de proyecto enfocado derivados.
- Las puertas de calidad de localización y lanzamiento son más estrictas, con higiene de cobertura de locale más amplia, mejores pruebas de regresión de i18n y límites de cobertura por archivo para código de nube y MCP.

## Móvil y Captura de Android

- Rediseñado el shell de pestaña móvil, pantalla de Enfoque, menú, páginas de configuración y flujo de captura rápida.
- Agregada captura de Configuración Rápida de Android y enrutamiento de captura de Acciones de Aplicación/asistente a través de enlaces profundos `CREATE_NOTE` y `mindwtr:///capture`.
- Mantenida captura desencadenada por asistente y externa como confirmación primero en lugar de guardar tareas silenciosamente.
- Se agregó startup tracing for Android capture entry points and tests for app shortcuts, quick capture, and startup ordering.
- Se hizo the daily review calendar collapsible and restored missing review modal translations.
- Se preservó mobile calendar day scroll position and made calendar labels, composer placeholders, and review copy use locale keys.
- Se reemplazó native-looking confirmation alerts with Mindwtr-themed alerts.
- Mejorado capture modal parsing, URL JSON sanitization, audio capture manejo, and quick capture picker behavior.

## Sync, Cloud & Data

- Se agregó saved filters as a syncable settings group with local SQLite storage, normalization, merge logic, tombstones, and delete-conflict manejo.
- Sincronizaed the Focus task limit and kept GTD sync timestamps se actualizó when synced GTD fields change.
- Se agregó mobile background sync task wiring and AppState abort manejo.
- Propagated cancellation through CloudKit, Dropbox, WebDAV, file, and cloud attachment sync paths.
- Se preservó caller abort errors so cancelled sync operations report the real cancellation reason.
- Se hizo WebDAV weak-fingerprint warnings clearer and avoided unsafe unchanged-sync shortcuts when validators are unreliable.
- Se alineó cloud HEAD and GET behavior by serving raw data bytes, matching content length, and skipping trusted GET parsing.
- Mejorado pending remote write and attachment sync behavior so local/remote work is not skipped while uploads or deletes are pending.

## Escritorio & Core Experience

- Persisted desktop view options and restored filters during startup.
- Abreed the desktop quick-add popup before refresh work can steal focus.
- Refined the sidebar sync footer and se eliminó stale board filter open state.
- Derived focused project counts from shared helpers and reused focused task count logic.
- Se agregó shared saved-filter helpers, labels, tests, and core exports.
- Mejorado fast sync helpers, local watcher behavior, sync service fingerprinting, and runtime sync coverage.
- Se ampliaron MCP and cloud server test/type/lint coverage.

## Localization, CI & Lanzamiento

- Routed mobile settings, review modal, calendar labels, and composer placeholders through locale keys.
- Eliminado mixed English partial locale entries and se agregó checks against verbatim English placeholders.
- Se agregó locale coverage hygiene and stricter locale parity checks.
- Repaired CI coverage gates, se agregó cloud/MCP coverage floors, and clarified LCOV manejo.
- Actualizado Android release workflow soporte for Google Play listing metadata preparation.
- Se resolvió Bun audit advisories and se actualizó shared lint/typecheck scripts for cloud and MCP packages.
