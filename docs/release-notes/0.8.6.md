# Mindwtr 0.8.6

## Destacados

- La planificación de escritorio es más clara con páginas de configuración de **Sincronización** y **Datos** separadas, mejor accesibilidad de diálogos, confirmación antes de eliminaciones permanentes de archivo/papelera y retroalimentación de conflicto/estado de sincronización más constante.
- Las tareas recurrentes son más completas en escritorio y móvil con condiciones de finalización para **Nunca**, **En fecha** y **Después de N ocurrencias**, un preajuste de duración de Pomodoro personalizado y copia traducida en cada idioma enviado.
- Los flujos de importación y sincronización son más sólidos con importación CSV de OmniFocus, creación automática de carpeta principal de WebDAV antes de PUTs, recorrido MKCOL acotado, fusiones heredadas deterministas y una corrección de devolución de llamada OAuth de Dropbox de macOS.
- El uso diario móvil es más seguro con correcciones de envío de teclado de captura rápida de iOS, endurecimiento de eliminación de envío de calendario, actualizaciones de lista de verificación que leen el conjunto completo de tareas y mejor comportamiento de reinicio del editor de tareas.

## Planificación de Escritorio, Configuración y Accesibilidad

- Dividida la configuración de escritorio en páginas de **Sincronización** y **Datos** dedicadas para que la transferencia, limpieza, diagnósticos y configuración del proveedor sean más fáciles de encontrar.
- Agregados avisos de confirmación antes de limpiar permanentemente Archivo o Papelera y expandida la cobertura de accesibilidad para diálogos, controles de recurrencia y copia de marcador de posición.
- Agregado preajuste de duración de Pomodoro personalizado para que las sesiones de enfoque del escritorio puedan mantener tiempos definidos por el usuario.
- Actualizado arte de escritorio, capturas de pantalla de AppStream/Flathub y documentos de instalación para que los metadatos de lanzamiento de Linux coincidan con la interfaz de usuario enviada.

## Sincronización, Importación e Fiabilidad

- Agregada importación CSV de OmniFocus con mapeo de proyecto/acción y actualizaciones de wiki/readme relacionadas.
- Creadas colecciones principales de WebDAV faltantes automáticamente antes de JSON/PUTs de archivo y limitada la profundidad de recorrido de MKCOL para rutas anidadas patológicas.
- Corregido el oyente de devolución de llamada OAuth de Dropbox de macOS para que las compilaciones automáticas de escritorio y los lanzamientos compatibles puedan completar el flujo de redireccionamiento local de manera confiable.
- Corregida la orquestación de sincronización de escritorio para que las ejecuciones de seguimiento en cola usen las últimas opciones de llamante, persistentes estado de sincronización exitoso antes de la actualización de tienda posterior a la sincronización y conflictos de sincronización expuestos de manera más clara en el diseño.
- Hecha la fusión heredada sin revisión determinista dentro de la ventana de desvío del reloj en lugar de preferir silenciosamente la marca de tiempo que fue algunos minutos más nueva.
- Rellenados índices de tareas faltantes durante la migración de SQLite, detenidas eliminaciones de tareas de lote de re-lápida de lápidas existentes y hecho `purgeDeletedTasks()` idempotente para filas ya purgadas. Las bases de datos locales muy grandes pueden ver un retraso de inicio único mientras se crean los índices.
- Preservados ID de tareas de envío de calendario móvil eliminados en toda la ventana de rebote para que las actualizaciones posteriores no eliminen remociones de calendario pendientes.

## Móvil, Localization & Daily Use

- Se agregó recurrence end conditions (`count`, `until`, and preserved `completedOccurrences`) so recurring tasks can stop after a set number of runs or on a target date.
- Filled the new recurrence end-condition copy into every shipped language and se agregó locale-parity coverage for those keys.
- Corregido iOS quick capture so the keyboard **Done** action saves the task instead of only dismissing the field.
- Reset mobile task-edit state more reliably on close and kept swipeable checklist flushes anchored to `_allTasks` instead of only the visible slice.
- Localized sync result toasts, sync failure copy, sync badge labels, accessibility labels, and desktop placeholder examples to keep cross-platform UI parity tighter.
- Actualizado CHANGELOG, README parity, Core API docs, recurrence guides, Dropbox self-build notes, and sync wiki pages to match shipped behavior.
