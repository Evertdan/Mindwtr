# Mindwtr 0.7.0

## Destacados
- Corregido a sync edge case where stale attachment references could block remote sync.
- Mejorado attachment validation and unrecoverable manejo to avoid repeated failing retries.
- Refined delete-vs-edit conflict manejo so genuinely newer edits are preserved while ties remain deterministic.
- Hardened CI and release workflows with stronger validation and safer automation defaults.

## Móvil
- Sync reliability se mejoró for attachment-heavy task/project data.
- Android FOSS release pipeline now enforces strict APK selection and stronger artifact checks.
- Kept FOSS permission policy explicit: unused camera/alert/storage permissions se eliminó, `RECORD_AUDIO` retained for voice notes.

## Escritorio
- Sync attachment validation integration is now consistent in TypeScript builds.
- Escritorio lint/type checks are now enforced more consistently in CI.

## Sync & Cloud
- Corregido attachment-state manejo that could trigger pre-remote-sync reference errors.
- Mejorado conflict resolution behavior for near-simultaneous delete/update operations.
- Agregado additional guardrails in cloud/release pipelines to reduce bad-release risk.

## Compilación & Lanzamiento
- Lanzamiento workflows now include stricter artifact integrity checks and required release notes.
- Android and iOS release pipelines include se mejoró cache/reliability settings.
- Wiki sync and Docker image metadata automation were modernized and hardened.
