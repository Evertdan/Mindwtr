# Mindwtr 0.6.14

## Destacados
- Endurecimiento importante de sincronización/integridad de datos en núcleo + nube (manejo de lápida, ruptura de empate determinista, estado de adjunto fusionado, seguridad de fusión de configuración y validación de carga remota).
- Mejoras del flujo de trabajo móvil para iOS y Android (procesamiento de bandeja de entrada de página única, mejor flujo de contexto/proyecto quick-add, ubicación mejorada del selector de fecha y encabezados de revisión diaria/edición de tarea más segura).
- Actualizaciones de confiabilidad de canalización de nube y lanzamiento (soporte de alias de env de autenticación de nube, corrección de flujo de publicación de metadatos de MS Store y protección de envío de iOS cuando la revisión previa aún está en progreso).
- Actualizaciones de rendimiento y capacidad de mantenimiento (ayudantes de sincronización compartida, optimización de fusión de ruta activa, jitter de reintento de FTS de SQLite, mejoras de selector/renderización y cobertura de prueba expandida).

## Núcleo Sync y Datos
- Se fusionaron escrituras `/v1/data` en sincronización en la nube para prevenir pérdida de datos basada en sobrescritura.
- Se endurecimiento de resolución de conflicto de eliminación vs. live y manejo de lápida inválida.
- Se filtraron lápidas purgadas expiradas antes de fusión.
- Se cambiaron rupturas de empate de dispositivo a comparación determinista sin configuración regional.
- Se aplicó siempre estado de adjunto fusionado y se preservó estado disponible local.
- Se fusionaron configuraciones seguramente incluso cuando las preferencias de sincronización están vacías.
- Se preservó ordenamiento de área fusionada y se limpiaron lápidas de adjunto eliminadas independientemente de eliminación de tarea principal.
- Se rechazaron formas de carga remota inválidas antes de fusión.

## Móvil
- Se rehizo el procesamiento de bandeja de entrada en un flujo de página única con navegación más rápida.
- Se mejoró quick add y experiencia del usuario de entrada de token (contextos/etiquetas/proyectos/áreas) incluyendo comportamiento de teclado de iOS.
- Se corrigió gestión de área/etiqueta del proyecto de iOS y se expandieron capacidades del administrador de áreas (flujos de renombramiento/color).
- Se corrigió ubicación de selector de fecha/hora y se mejoró comportamiento de área segura en revisión diaria y búsqueda global.
- Se aumentó objetivo de toque de barra superior y edición de tarea clave.
- Se agregó detección adicional de error de red sin conexión y seguridad de desaceleración de lista de verificación.

## Escritorio / Nube / CI
- Se agregó comprobación previa sin conexión de escritorio para sincronización remota.
- Se agregó soporte de alias de env de token de autenticación de nube y documentos alineados.
- Se corrigió flujo de lanzamiento de MS Store para publicar el envío de borrador existente con metadatos.
- Se agregó protección de lanzamiento de iOS para omitir envío de revisión si una versión de aplicación anterior aún está en revisión.

## Rendimiento / Refactorización / Pruebas
- Se extrajeron utilidades de servicio de sincronización compartida en núcleo.
- Se omitió serialización de diferencia de contenido costosa cuando las revisiones ya determinan el resultado del conflicto.
- Se agregó jitter a reintentos de bloqueo FTS y se mantuvo adquisición de bloqueo atómica.
- Se mejoró comportamiento de recorte de lista móvil para listas grandes.
- Se agregó orquestación de sincronización de escritorio y cobertura de acción de sección; se expandieron pruebas de regresión de sincronización.
- Se estandarizaron API de almacén de estado con migración `createWithEqualityFn`.
