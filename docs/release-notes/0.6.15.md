# Mindwtr 0.6.15

## Destacados
- Se agregó soporte para **puntos finales de IA compatibles con OpenAI locales** (por ejemplo Ollama/LM Studio/LocalAI/vLLM) a través de URL base personalizada.
- Endurecimiento importante de sincronización/integridad de datos en núcleo y nube (comportamiento de bloqueo de escritura, seguridad de marca de tiempo de eliminación, consistencia de fusión de adjuntos y comprobaciones más fuertes de integridad de SQLite).
- Mejoras de experiencia del usuario móvil en iOS y Android (estabilización de navegación de retroceso de iOS, visibilidad de teclado de lista de verificación de Android, pulido de barra de estado/tema y mejoras de flujo de bandeja de entrada/revisión).
- Actualizaciones del servidor MCP para confiabilidad y rendimiento (mutaciones transaccionales, limpieza de validación con tipo, búsqueda basada en FTS, análisis quick-add compartido y pruebas expandidas).
- Mejoras de lanzamiento/distribución (automatización oficial de cask de Homebrew, correcciones de flujo de trabajo de App Store/TestFlight y actualizaciones de canalización de Microsoft Store).

## Núcleo / Sincronización / Nube
- Se agregó manejo conservador para marcas de tiempo inválidas de `deletedAt` y se corrigió comportamiento de fusión de URI/metadatos del ganador de adjunto.
- Se endurecimiento de continuación de cola de bloqueo de escritura de nube y se mejoró seguridad de serialización de escritura.
- Se agregó validación de integridad de datos de SQLite en capa DB (validación de estado de tarea/proyecto + validación de campo JSON) e índices compuestos nuevos orientados a sincronización.
- Se compartieron ayudantes de cliente de sincronización en escritorio/móvil para reducir duplicación y mantener comportamiento alineado.
- Se mejoró TTL de caché de configuración de sincronización móvil y varias rutas de corrección de fusión/tiempo de ejecución.

## Escritorio / Móvil
- Se estabilizó navegación de retroceso de gaveta/configuración de iOS y comportamiento de gesto.
- Se corrigió visibilidad de entrada de título de lista de verificación de Android arriba del teclado y se mejoró tema de barra de estado de Android.
- Se mejoró flujo de procesamiento de bandeja de entrada móvil y sugerencias de contexto de copiloto.
- Se mejoró comportamiento de revisión semanal/calendario para tareas programadas y debidas.
- Se agregó retroalimentación consistente de carga/error asincrónica en flujos de lista/proyectos de escritorio.
- Se mejoró cobertura de accesibilidad/i18n de escritorio y suscripciones de selector agrupado para mejor capacidad de mantenimiento.

## IA / MCP / Búsqueda
- Se agregó soporte de punto final compatible con OpenAI local a través de configuración de URL base personalizada.
- El servidor MCP ahora usa búsqueda de tarea FTS5 (con alternancia), envuelve mutaciones de tarea en transacciones y valida entradas con tipo sin casts inseguros.
- La cobertura de pruebas de registro/herramienta del servicio MCP se expandió.

## Empaquetado / Documentación / CI
- Se cambió documentación de instalación de Homebrew de macOS a `homebrew/cask` oficial y se agregó flujo de trabajo de actualización de cask automática.
- Se eliminó nota de solución alternativa de cuarentena de macOS obsoleta después de cambios de canalización de firma.
- Se expandió orientación de wiki de sincronización/pruebas y se aclaró documentación de Recurrencia Fluida.
- Se mejoró confiabilidad de CI/flujo de trabajo en publicaciones de iOS/macOS/Windows y canalizaciones de metadatos.
