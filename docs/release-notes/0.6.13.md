# Mindwtr 0.6.13

## Destacados
- Endurecimiento importante de confiabilidad de sincronización en núcleo, escritorio y móvil (persistencia de revisión, abortos de cambio local, exposición de error en cola y comportamiento de fusión más seguro).
- Mejoras de seguridad y estabilidad de adjuntos en la nube (endurecimiento de travesía de ruta, límites de velocidad de punto final y tiempo de espera/reintento de carga).
- Mejor experiencia del usuario y accesibilidad de escritorio/móvil (confirmación de eliminación + deshacer, etiquetas mejoradas, marcadores de posición localizados, esqueletos de carga y objetivos de toque móvil más grandes).
- Gran refactorización e impulso de capacidad de prueba (cobertura de orquestación de sincronización, pruebas de integración de API en la nube, ayudantes de tiempo de ejecución de sincronización compartida y división de componentes).
- Pulido de escritorio de Linux: el menú superior nativo ahora es solo de macOS, y el manejo de metadatos/icono de aplicación de Linux se mejoró.

## Núcleo Sync y Datos
- Persistencia de `rev`/`revBy` en SQLite para que los metadatos de resolución de conflictos sobrevivan a guardar locales.
- Ignorar valores inválidos de `deletedAt` para ruptura de empate de tiempo de operación.
- Preservar `updatedAt` ganador durante normalización de marca de tiempo.
- Detectar divergencia de contenido cuando las revisiones se empatan.
- Fusionar configuración por campo dentro de grupos de sincronización.
- Mantener instantánea pendiente después de fallos de guardado para reducir riesgo de pérdida de datos.

## Escritorio
- Se borró temporizador de desaceleración de sincronización externo huérfano al detener observador.
- Se capturó marca de tiempo de instantánea local después de vaciado pendiente para evitar abortos obsoletos falsos.
- Se agregó tiempo de espera/reintento para cargas de adjuntos en la nube.
- Se agregó confirmación de eliminación de tarea y recuperación de notificación emergente de deshacer.
- Se mejoraron etiquetas de accesibilidad de metadatos/adjuntos.
- Se agregó esqueleto de carga de búsqueda global.
- Se mantuvieron selectores de proyecto/sección/área dentro de la vista.
- Se refactorizaron internos del editor de tarea/proyecto y se dividieron módulos oversized.

## Móvil
- Se agregó protección de aborto de sincronización de cambio local y manejo de aborto de sincronización en vuelo.
- Se agregó comportamiento de aborto de sincronización sin conexión/caída de red para solicitudes HTTP de sincronización.
- El backend de sincronización predeterminado ahora es `off` para paridad de primer lanzamiento.
- Se localizaron marcadores de posición de etiqueta hardcoded.
- Se desinfectaron alertas de falla de sincronización para evitar exponer errores internos sin procesar.
- Se aumentó el tamaño de objetivo de toque de edición de tarea.
- Se almacenó en caché las lecturas de configuración de sincronización entre ciclos.
- Se limitó trabajo de limpieza de adjuntos por ciclo de sincronización.

## Nube / MCP / FOSS
- Se endurecimiento de resolución de ruta de adjuntos de nube.
- Se agregó limitación de velocidad específica del punto final de adjuntos.
- Se agregó opción de lista de permitidos de token portador de nube exigible.
- Se fortaleció validación de carga de datos de aplicación de nube.
- Se reutilizó conexión SQLite en servidor MCP para reducir sobrecarga.
- Se mantuvieron prep APK FOSS estable y flujo de firma CI alineado.

## Pruebas y Refactorización
- Se agregaron pruebas de orquestación de sincronización de escritorio y móvil.
- Se agregaron pruebas de integración de API de nube.
- Se agregaron ganchos de restablecimiento del servicio de sincronización de escritorio para aislamiento de pruebas.
- Se cargó de forma perezosa la dependencia Expo FS del registrador móvil para compatibilidad de pruebas de Node.
- Se extrajeron ayudantes de tiempo de ejecución de sincronización compartida en `@mindwtr/core`.
- Se unificó manejo de mapa/bucle de adjuntos en todos los backends de sincronización de escritorio.
