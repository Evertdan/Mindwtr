# Mindwtr 0.5.3

## Destacados
- **Sincronización de adjuntos (WebDAV + Auto‑alojado)**: carga/descarga con progreso, comprobaciones de integridad, reintentos y limpieza de huérfanos.
- **Soporte RTL/LTR por tarea**: establecer la dirección del texto por tarea (auto/ltr/rtl) en escritorio y móvil.
- **Actualizaciones del servidor MCP**: actualizaciones de README y orientación de CLI para integración de LLM.

## Escritorio
- Interfaz de usuario de progreso de adjuntos + limpieza.
- Opciones de modelo de voz a texto expandidas.
- Corrección de lint de expresión regular y mejoras de manejo de carga binaria.

## Móvil
- Estados de interfaz de usuario de descarga de adjuntos + progreso.
- Protección de OOM de descarga sin conexión de Whisper.
- Fontanería de sincronización de adjuntos + reintento.

## Núcleo/Sincronización
- Validación de adjuntos, hash, seguimiento de progreso, reintentos y utilidades de limpieza.
- Puntos finales de adjuntos de nube/WebDAV.
- Manejo de carga binaria normalizado para hash + cargas.

## Empaquetado/CI
- Automatización de actualización de Homebrew/Scoop y envío de PR de Winget en flujo de trabajo de lanzamiento.
- Regeneración de `.SRCINFO` de AUR.
