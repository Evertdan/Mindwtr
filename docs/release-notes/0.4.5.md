# Mindwtr 0.4.5

## Destacados
- Las Áreas de Enfoque para proyectos, más las etiquetas de proyecto, ahora se admiten en el núcleo y la interfaz de usuario.
- La recurrencia semanal admite días de la semana específicos (por ejemplo, lun/mié/vie).
- Soporte de intención de compartir de Android para que Mindwtr pueda aparecer en el menú Compartir del sistema.
- Los ajustes se simplifican y reorganizan para reducir la carga cognitiva.

## Escritorio
- Los ajustes GTD ahora incluyen interruptores de características (Prioridades / Estimaciones de tiempo).
- Las notificaciones de Revisión Semanal están disponibles en Ajustes → Notificaciones.
- Las decoraciones de ventana de Niri se deshabilitan automáticamente para adaptarse bien a los mosaicos.
- El diseño del editor de tareas utiliza etiquetas Mostrado/Oculto para mayor claridad.

## Móvil
- Los Ajustes ahora tienen un submenú General (Apariencia + Idioma).
- Las notificaciones de Revisión Semanal se muestran en Notificaciones.
- Alineación de iconos de pestaña inferior y correcciones de restablecimiento de pestaña del editor de tareas.
- Los ganchos de intención de hoja de compartir de Android están habilitados.

## Núcleo
- Las Áreas de Enfoque y las etiquetas de proyecto forman parte del modelo de datos.
- La recurrencia respeta las reglas de días de la semana (BYDAY).

## Documentación
- Filosofía de LEÉME actualizada y estructura de ajustes wiki.
