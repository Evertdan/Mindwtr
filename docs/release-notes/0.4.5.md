# Mindwtr 0.4.5

## Destacados
- Areas of Focus for projects, plus project tags, are now supported across core and UI.
- Weekly recurrence supports specific weekdays (e.g., Mon/Wed/Fri).
- Android share intent soporte so Mindwtr can appear in the system Share menu.
- Settings are simplified and reorganized to reduce cognitive load.

## Escritorio
- GTD settings now include característica toggles (Priorities / Time estimates).
- Weekly Review notifications are available in Settings → Notifications.
- Niri window decorations are disabled automatically to play nice with tiling.
- Task editor layout uses Shown/Hidden labels for clarity.

## Móvil
- Settings now have a General submenu (Appearance + Language).
- Weekly Review notifications are surfaced in Notifications.
- Bottom tab icon alignment and task editor tab reset fixes.
- Android share sheet intent hooks are enabled.

## Core
- Areas of Focus and project tags are part of the data model.
- Recurrence respects weekday rules (BYDAY).

## Docs
- Actualizado README philosophy and wiki settings structure.
