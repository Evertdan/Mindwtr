# Mindwtr 0.6.10

## Destacados
- Se corrigió un caso límite de conflicto de sincronización que podría revertir ediciones más nuevas cuando las revisiones eran iguales, mejorando la estabilidad entre dispositivos.
- Se endurecimiento del flujo de lanzamiento de Android de FOSS para IzzyOnDroid/F-Droid: comportamiento de compilación reproducible, limpieza de permisos y documentos de compilación npm + Gradle simples.
- Se mejoró el flujo de revisión y experiencia de usuario de edición de tablero con comportamiento de revisión de calendario más claro y un modal de edición de tarea de tablero más tradicional.
- Se pulió la interfaz de usuario de proyecto/flujo de trabajo de escritorio con una estructura de diseño mejorada, manejo de max-width y estilos de lista basados en divisores.

## Sincronización y Confiabilidad
- Se corrigió la lógica de ruptura de empate de revisión para preferir marcas de tiempo más nuevas antes de ordenamiento de id de dispositivo.
- Se fortaleció diagnósticos de sincronización e informes de conflictos en tareas/proyectos/secciones/áreas.
- Continuación del endurecimiento de sincronización de adjuntos y comportamiento de fusión local/remota en escritorio y móvil.

## Móvil
- Se agregó autocompletado de sugerencias @/# con chips de contexto/etiqueta rápida en flujos de edición de tareas.
- Se corrigió el comportamiento del selector de tiempo de configuración de iOS.
- Se refinaron patrones de interacción de edición de tablero y tareas.

## Escritorio
- Se refinó la estructura de la página del proyecto (espaciado de diseño, restricciones de max-width, alineación y jerarquía visual).
- Se expandió la presentación de lista de estilo divisor sin bordes para mejorar la escala para conjuntos de tareas grandes.

## FOSS / Distribución
- Se agregó y validó una receta de compilación compatible con Izzy (`config/izzyonandroid.yml`) usando npm + Gradle (sin requisito de Bun/EAS).
- Se agregaron comprobaciones de lanzamiento de FOSS y endurecimiento de reproducibilidad en scripts de compilación de Android móvil.
- Continuación de actualizaciones de metadatos/lista de tienda para F-Droid/IzzyOnDroid y Microsoft Store.
