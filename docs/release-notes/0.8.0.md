# Mindwtr 0.8.0

## Destacados
- Esta versión agrega fechas de vencimiento de proyectos opcionales, una compilación de escritorio portátil de Windows y una pasada amplia de endurecimiento de sincronización y almacenamiento en escritorio y móvil.
- La planificación de proyectos de escritorio es más suave con selección de barra lateral de un solo clic, una sección separada de proyectos archivados, mejor contraste de calendario y revisión y secciones de editor de tareas en línea configurables.
- La sincronización móvil es más constante con marcadores de sincronización de archivos de iOS persistentes, agrupación de proveedores de nube más clara y widgets que ajustan listas de tareas a partir de dimensiones reales de widgets.
- La sincronización ahora expone metadatos de desvío del reloj, conserva ediciones realizadas durante la recuperación de escritura remota, rastrea marcas de tiempo de eliminación inválidas y mantiene adjuntos eliminados fuera de datos de tareas visibles.

## Escritorio y Planificación
- Agregadas fechas de vencimiento de proyecto opcionales en el modelo de datos compartido, adaptador SQLite de JavaScript y esquema de almacenamiento de escritorio, incluyendo migración de datos de escritorio existentes.
- Se agregó modo de distribución portátil de Windows con almacenamiento de perfil y configuración local junto al ejecutable.
- Mejorada la navegación de proyectos de escritorio con selección de barra lateral de un solo clic, una sección separada de proyectos archivados, mejor contraste de calendario y revisión y controles de enfoque localizados en filas de proyectos y tareas.
- Se agregós valores predeterminados de sección del editor de tareas en línea, mantenida la integración de Obsidian contraída de forma predeterminada y actualizado documentos de escritorio/wiki para instalaciones portátiles y nuevos campos de proyectos.

## Móvil, iOS y Android
- Los widgets móviles ahora usan la altura real del widget para decidir los límites de tareas, y las cargas útiles del widget de iOS son adaptables con una carga más ligera para lectores de widgets más antiguos.
- La sincronización de archivos de iOS ahora persiste marcadores de ámbito de seguridad de manera más confiable después de la selección de carpetas.
- Agrupada la sincronización de iCloud bajo proveedores de nube y mantenidos los accesorios de prueba de widget y sincronización móvil alineados con los cambios de estadísticas de fusión compartida.

## Datos, Sincronización y Almacenamiento
- Agregada indexación de fecha de vencimiento del proyecto y migración para los adaptadores SQLite de Rust y JavaScript.
- Mejorados diagnósticos de fusión exponiendo desvío del reloj grande, rastreando marcas de tiempo eliminadas inválidas y haciendo que la recuperación de escritura remota pendiente incluya ediciones realizadas durante el retroceso.
- Endurecidas las reglas de visibilidad usando el ayudante compartido de tarea visible de manera consistente, aplicando límites de enfoque de tareas, filtrando adjuntos eliminados de manera suave de tareas visibles y haciendo la deduplicación de etiquetas determinista después de cambiar el nombre.
- Mejorada la seguridad del almacenamiento de escritorio en Windows con escrituras atómicas basadas en copia de seguridad, y emitido un evento de advertencia cuando los secretos vuelven al texto sin formato porque el llavero no está disponible.
- La búsqueda ahora maneja tareas y proyectos archivados de manera consistente.

## Documentación, CI y Arquitectura Interna
- Actualizada la página MCP de wiki para los nuevos campos dueDate y reviewAt y actualizada la configuración de prueba de Bun de escritorio para exponer los globales DOM que Bun pierde.
- Corregidas regresiones de TypeScript de ventana de lanzamiento en tipificaciones de sincronización compartida y datos de accesorios móviles.
- Continuada la limpieza alrededor de tipificaciones de widgets, metadatos de empaquetado de escritorio e infraestructura de lanzamiento.
