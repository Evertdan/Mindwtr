# Mindwtr 0.6.7

## Destacados
- Corregir transferencias de adjuntos de WebDAV usando credenciales almacenadas.
- Los toques del widget de Android ahora abren Focus (el botón de captura rápida no cambia).
- Se eliminó la sugerencia de pausa de vista de tablero para un diseño más limpio.

## Escritorio
- La sincronización de adjuntos de WebDAV ahora usa contraseñas almacenadas para cargas/descargas confiables.
- Sugerencia de pausa de vista de tablero oculta para reducir desorden visual.
- Las acciones de tareas ya no muestran la insignia del proyecto en listas compactas.

## Móvil
- El toque del widget de Android abre la vista de Focus.

## Sincronización
- Se mejoró la confiabilidad de la sincronización de adjuntos de WebDAV.

## CI/Lanzamiento
- Restaurar notarización de macOS en el flujo de trabajo de lanzamiento.
- Flujo de envío de Microsoft Store alineado con orientación de CLI de msstore.

## Documentación
- Se agregaron recomendaciones de sincronización y se actualizaron insignias de plataforma.
- Disponibilidad de iOS TestFlight y notas de compilación documentadas.
