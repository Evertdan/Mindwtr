# Mindwtr v0.5.0

## Destacados
- Nuevo selector de tema en móvil con Material 3 Claro/Oscuro más E‑Ink, Nord, Sepia y OLED (Medianoche).
- Escritorio ahora incluye temas E‑Ink, Nord y Sepia.
- Los encabezados de móvil y las barras de navegación ahora siguen el tema activo.
- Las acciones de la lista de proyectos en móvil coinciden con escritorio (icono de papelera + reorder a la derecha).

## Seguridad
- Las claves de API de IA ahora usan almacenamiento seguro en móvil (SecureStore) y configuración nativa en escritorio.
