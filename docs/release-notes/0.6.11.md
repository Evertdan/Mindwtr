# Mindwtr 0.6.11

## Destacados
- Se corrigieron problemas de estabilidad de inicio de Android vistos en compilaciones de Play 0.6.10 (incluyendo bloqueos de inicio de `undefined is not a function`).
- Se corrigió navegación de inicio no intencionada a Revisión causada por reproducción de respuesta de notificación obsoleta.
- Se endurecimiento de limpieza de adjuntos + manejo de lápida de sincronización para que las eliminaciones de adjuntos de audio se propaguen confiablemente en todos los dispositivos.
- Se agregó agrupación basada en área para elementos de Referencia para mejorar la organización a escala.

## Móvil
- Se endurecimiento del flujo del proveedor de inicio para evitar errores de tipo de tiempo de ejecución durante la inicialización.
- Se evitó que cargas de apertura de notificación obsoletas forzaran la pantalla de Revisión en el lanzamiento de la aplicación.
- Se borró la última respuesta de notificación después del manejo para evitar el comportamiento de enlace profundo repetido al reiniciar.
- Se endurecimiento de resolución de ayudante de limpieza de adjuntos en la ruta de sincronización móvil.

## Sincronización e Integridad de Datos
- Se preservaron lápidas de adjuntos durante la limpieza para que las eliminaciones se sincronicen correctamente entre dispositivos.
- Se separaron objetivos de limpieza de archivos del comportamiento de retención de lápida de metadatos para limpieza más segura entre dispositivos.

## Referencias
- Se agruparon elementos de Referencia por Área para categorización y navegación más limpia.
