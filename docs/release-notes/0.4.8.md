# Mindwtr 0.4.8

## Destacados
- Preparación de F‑Droid/IzzyOnDroid: se agregaron scripts de compilación FOSS y se actualizó la receta para compilaciones limpias y sin firmar.
- Proyectos: reordenamiento de arrastrar y soltar para áreas y proyectos (escritorio + móvil).
- Móvil: el selector de color de área siempre es visible en el Administrador de Áreas y los colores se propagan a proyectos/tareas.

## Detalles
- Se agregaron scripts de preparación de compilación FOSS (`fdroid_prep.sh`, `fdroid_strip_deps.js`) para eliminar dependencias que no son FOSS en compilaciones de origen.
- El script de compilación de Android ahora admite `UNSIGNED_APK=1` para la firma del lado del generador.
- La edición de proyecto móvil ahora se desplaza correctamente; la lista de tareas dentro del modal ya no roba el desplazamiento.
- Núcleo: orden del proyecto persistido en SQLite + migración de tienda para soportar reorder.
