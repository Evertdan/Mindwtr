# Mindwtr 0.4.3

## Destacados
- Adjuntos de escritorio: el campo **Agregar enlace** ahora acepta rutas de archivo local (por ejemplo, `/home/user/file.pdf`, `C:\Users\you\file.txt`, `file://...`).
- Registro de diagnósticos: controles más claros y redacción más segura para credenciales de WebDAV/nube, claves de IA y URLs de calendario ICS.
- Compilaciones de Android: APKs arm64 de división ABI y salida de lanzamiento más pequeña para IzzyOnDroid/F‑Droid.

## Escritorio
- Permitir rutas de archivo en la solicitud de adjunto de enlace.
- Corregir la limpieza del registro de diagnósticos.

## Móvil / Android
- Nuevo `apps/mobile/scripts/android_build.sh` para compilar APKs arm64 localmente con Gradle.
- Divisiones ABI habilitadas; marcas de reducción de tamaño habilitadas (minificar, encogimiento de recursos, empaquetado heredado).
- El flujo de trabajo de Lanzamiento de GitHub se actualizó para usar el script de compilación de Gradle.

## Documentación
- Se agregó borrador de receta de IzzyOnDroid.
- Instrucciones de compilación móvil actualizadas.
