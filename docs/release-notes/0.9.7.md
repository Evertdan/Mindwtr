# Mindwtr 0.9.7

## Destacados

- La configuración de primer lanzamiento es más clara en escritorio y móvil, con una guía de Primeros pasos más completa, acciones de recuperación y comportamiento de instalación vacía más seguro.
- Enfoque y edición de tareas son más constantes: Enfoque se abre de manera más consistente, los valores predeterminados del editor de tareas son más delgados, las acciones diferidas son más fáciles de planificar y las fechas incoherentes se marcan.
- El trabajo de tareas de escritorio es más rápido con reordenamiento de arrastre de lista de verificación, autocompletado de metadatos, controles de selección en lote, etiquetas más claras y navegación de proyecto contraída mejor.
- La sincronización y la seguridad de datos mejoran con selección de backend más clara, limpieza de caché de sincronización rápida obsoleta, lápidas de fusión de área preservadas y solicitudes de asistente de IA más seguras.
- Plataforma integration is quieter across Android context automation and Linux Flatpak tray/launch manejo, with refreshed install and sync documentation.

## Onboarding & Configuración

- Se agregó first-run setup flows on desktop and mobile.
- Se ampliaron the seeded Primeros pasos guide and backfilled it for older local installs.
- Se agregó desktop recovery actions and handoffs so onboarding choices remain recoverable.
- Se preservó an empty first-run state for local installs before sync is enabled.
- Se mantuvo the mobile Data settings page focused by keeping starter-guide creation in first-run setup instead of a permanent recovery card.
- Se aclaró install and sync guidance in README, app docs, wiki pages, and issue templates.

## Focus, Planning & Task Editing

- Se mantuvo Focus as the mobile home tab and streamlined the desktop Focus header and filters.
- Se agregó a Focus defer action for moving next actions out of today's active list.
- Se agregó task date-coherence warnings for mismatched start, due, and review timing.
- Leaned task editor defaults and se mejoró mobile task editor layout and interaction performance.
- Corregido transparent project overlay modals so Android no longer warns about incompatible full-screen modal presentation.
- Se hizo task modal titles, labels, done focus, and task status feedback easier to scan.
- Respected cleared task project fields so se eliminó project links stay se eliminó.

## Escritorio Productivity

- Se agregó checklist drag-and-drop reorder with a more visible drag handle.
- Se agregó metadata autocomplete for project, context, tag, assignee, priority, energy, location, time estimate, and recurrence fields.
- Completed token matching for metadata autocomplete and allowed multiple inbox context tokens.
- Se agregó bulk selection controls across desktop Select-mode views.
- Se ampliaron the project workspace when the list collapses and refined collapsed board icons.
- Se agregó Traditional Chinese settings labels.

## Sync, Automation & Reliability

- Se aclaró sync backend selection and se mejoró sync setup copy.
- Se evitó stale fast-sync cache entries after cleanup.
- Se preservó area merge tombstones so deleted areas do not reappear during merge.
- Se fortaleció assistant requests and provider manejo.
- Se redujo task editor stalls on large mobile stores and se agregó a large-store performance guard.
- Quieted Android context automation triggers.
- Se restauró locale and contrast checks in CI.

## Linux & Distribution

- Usad an app cache directory for Flatpak tray icon files.
- Mejorado Flatpak-facing launch handoff behavior.
- Actualizado Flathub checkout automation.
- Se actualizó install-channel issue templates for better release reports.
