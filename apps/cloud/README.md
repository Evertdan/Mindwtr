# Mindwtr Nube

Este paquete proporciona el backend de sincronización ligero utilizado por los clientes de Mindwtr.

## Inicio Rápido

Ejecuta desde la raíz del repositorio:

```bash
bun run --filter mindwtr-cloud dev -- --port 8787
```
